分布histogram

单个连续变量的分布

何时用：一个连续变量的形状、尾部与多峰。

geom：geom_histogram(binwidth = ...) + 可选 geom_density()。

不推荐：默认组距不写进图注；用柱状图替代分布。

ggplot(pika, aes(hemoglobin_g_l)) +
  geom_histogram(binwidth = 5, boundary = 0,
                 fill = "#56B4E9", colour = "white") +
  labs(x = "Haemoglobin (g/L)", y = "Count")
教材：ch10示例图
比较box + jitter

组间比较（小 n 必看）

何时用：组间比较且每组 n 小（< 30）；要同时显示中位数、IQR 与个体。

geom：geom_boxplot(outlier.shape = NA) + geom_jitter()。

不推荐：均值柱 + 误差线掩盖分布；箱线图不标 n。

ggplot(pika, aes(altitude_group, body_mass_g)) +
  geom_boxplot(width = .55, outlier.shape = NA) +
  geom_jitter(width = .12, alpha = .45, size = .7)
教材：ch08示例图
比较strip

极小样本的分布

何时用：每组 n ≤ 10，箱线图会过度概括。

geom：条带图 + 中位数横线（stat_summary）。

不推荐：只画均值点，看不到个体。

ggplot(pika, aes(altitude_group, hemoglobin_g_l)) +
  geom_jitter(width = .08, size = 1, alpha = .7) +
  stat_summary(fun = median, geom = "crossbar", width = .4)
教材：ch02示例图
比较mean ± SE + letters

多组均值与事后字母

何时用：ANOVA 之后展示组均值与校正后差异（字母）。

geom：geom_pointrange() + geom_text(label = .group)。

不推荐：字母用手写；误差线不写 SD/SE。

ggplot(d, aes(altitude_group, emmean)) +
  geom_pointrange(aes(ymin = emmean - SE, ymax = emmean + SE)) +
  geom_text(aes(label = .group), vjust = -1.6)
教材：ch12示例图
关系scatter + lm

两连续变量的关系与趋势

何时用：看两变量的方向、强度与非线性；回归线作趋势示意。

geom：geom_point() + geom_smooth(method = "lm", se = TRUE)。

不推荐：外推到采样范围外；把置信带当预测带。

ggplot(hb, aes(altitude_m, hemoglobin_g_l)) +
  geom_point(size = 1.2, alpha = .6) +
  geom_smooth(method = "lm", formula = y ~ x, se = TRUE)
教材：ch13示例图
关系facet

分组后模式是否改变

何时用：同一关系在亚组中是否一致（如性别分面）。

geom：facet_wrap(~ group, nrow = 1)；共享标度。

不推荐：scales = "free_y" 抹平面板间差异。

ggplot(pika, aes(altitude_group, body_mass_g)) +
  geom_boxplot(outlier.shape = NA) +
  facet_wrap(~sex, nrow = 1)
教材：ch08示例图
趋势line

重复测量的时间趋势

何时用：同一批个体在多个时间点的变化。

geom：geom_line(aes(group = id)) + 均值线。

不推荐：把个体点连成锯齿；忽略个体内相关。

ggplot(rep, aes(timepoint, body_mass_g, group = id)) +
  geom_line(alpha = .4) +
  stat_summary(aes(group = 1), fun = mean, geom = "line", linewidth = .8)
教材：ch11数据：重复测量
组学volcano

差异表达火山图

何时用：展示效应量（log2FC）与显著性（−log10 padj）的联合分布。

geom：geom_point() + 阈值线 + 标注少数基因。

不推荐：只标 p 不标 padj；标注几十个基因造成重叠。

ggplot(de, aes(log2FoldChange, -log10(padj))) +
  geom_point(aes(colour = significant), size = 1, alpha = .7) +
  geom_vline(xintercept = c(-1, 1), linetype = 2) +
  geom_hline(yintercept = -log10(0.05), linetype = 2)
教材：ch18数据：counts
生存km

生存曲线：删失与风险表

何时用：结局是「到事件发生的时间」，个体随访长短不一，未发生事件的个体只能算删失。

geom：survfit(Surv(time, status) ~ group) 估计 KM 曲线；风险表用 summary(fit, times = ...) 取每个时间点的风险人数。

不推荐：把删失当缺失删掉；只报 log-rank p，不报 HR 与曲线本身。

fit <- survfit(Surv(time_days, status) ~ treatment, data = d)
summary(fit, times = c(0, 20, 40, 60))
plot(fit, conf.int = TRUE, col = c("#0072B2", "#D55E00"))
教材：ch16数据：生存

配色库与期刊预设

色盲安全优先；分类 > 8 组改用分面。

期刊预设

  • 单栏 89 mm；双栏 183 mm；字号 7–9 pt。
  • 矢量：PDF（cairo_pdf 嵌入字体）或 SVG；位图仅作投稿系统备用（≥ 300 dpi）。
  • 图注：n、误差定义、统计方法、软件版本。

改图前后：三个常见反例

反例 1

均值柱 + 误差线 → 箱线 + 散点

柱状图把分布、离群值和 n 全部藏起来。改为箱线图 + 个体点，并在图注写 n = 20/组。

反例 2

彩虹色 → Okabe–Ito

彩虹色在色盲与灰度打印下不可辨。改为 Okabe–Ito 并加形状/线型冗余编码。

反例 3

截图导出 → 89 mm 矢量

屏幕截图会跑版。改为 ggsave(units = "mm", device = cairo_pdf)，并按终稿尺寸检查字号。
