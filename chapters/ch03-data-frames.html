数据框与 tidy 数据：一张表就是一次实验

60 行、11 列、一行一个个体——统计的一切都建立在这张表的形状约定上。

本章科研问题：一张样本表怎样才算「一行一个个体」？

85 MIN前置 ch02数据 pika_physiology.csv交付 metadata_tidy.csv · data_dictionary.csv

学习目标

  • 读入数据框并用 glimpse() 说出维度、列类型与前三行。
  • 用 $ 与 [row, col] 取出单个值、一行和一列。
  • 说出 tidy 三原则，并判断一张表是否 tidy。
  • 检查 ID 唯一性（duplicated() / distinct()）。
  • 把分组列设为有序因子并验证各组 n。
  • 写出一份含单位、缺失与允许范围的数据字典。

前置：第 2 章；数据：pika_physiology.csv；交付：metadata_tidy.csv、data_dictionary.csv。

样本表在导师和仪器之间传来传去。有人把三次测量的血压拆成三列，有人把两组数据摞在一张 Excel 里，还有人在表头写「3月5日体重①」。这一章立规矩：一行是一个个体，一列是一个变量，一张表是一次实验。

1. 数据框：列的列表

数据框（data frame）是一组等长向量的集合：每列一个向量（类型可以不同），每行一个观测。tibble 是 tidyverse 的现代版数据框——打印更聪明（只显示前 10 行和列类型）、从不悄悄改名。

示例 1：读入样本表并查看四个关键列

pika <- read_csv(here::here("assets/data/pika_physiology.csv"),

3. tidy 三原则与 ID 检查

tidy 数据（Wickham, 2014）三条约定：一行一个观测、一列一个变量、一张表一个分析单位。违背任何一条，统计和画图都会多绕路。判断的第一步永远是 ID 唯一性。

示例 3：ID 唯一性检查

duplicated · distinct科研必会
library(readr); library(dplyr)
pika <- read_csv(here::here("assets/data/pika_physiology.csv"),
                 show_col_types = FALSE)
dup_id <- pika$id[duplicated(pika$id)]
length(dup_id)
pika |> distinct(id) |> nrow()
R console
[1] 0
[1] 60

逐行解释

  • 第 4 行：duplicated() 标出第二次及以后出现的 ID；本数据 0 个重复。
  • 第 5 行：双保险——distinct() 去重后仍 60 行，等于「每个 ID 恰好一行」。

常见错误

只在 Excel 里「肉眼看看」ID。60 行看得过来，6000 行看不过来；重复个体会把 n 虚增、把 p 值做小（第 15 章伪重复的伏笔）。

4. 因子化分组列

示例 4：海拔组设为有序因子

factor · levels建模前置
library(readr); library(dplyr)
pika <- read_csv(here::here("assets/data/pika_physiology.csv"),
                 show_col_types = FALSE)
pika_tidy <- pika |>
  mutate(altitude_group = factor(altitude_group,
    levels = c("low", "mid", "high"), ordered = TRUE))
levels(pika_tidy$altitude_group)
table(pika_tidy$altitude_group)
R console
[1] "low"  "mid"  "high"

 low  mid high 
  20   20   20

逐行解释

  • 第 4–6 行：第一条管道——mutate() 原地替换 altitude_group 为有序因子。
  • 第 7 行：levels() 确认顺序 low → mid → high（海拔是有序变量）。
  • 第 8 行：各组 20 只，3 × 2 × 10 设计对上了。

5. 数据字典：给每个变量建档

数据字典（data dictionary）逐变量记录名称、类型、单位、缺失含义与允许范围。它是样本表的「标签」——三个月后你、审稿人、合作者都靠它读懂数据。

示例 5：用 tribble() 起草数据字典

tribble科研必会
library(readr); library(dplyr)
dict <- tribble(
  ~variable,         ~type,  ~unit,  ~missing, ~allowed_range, ~description,
  "id",              "chr",  "-",    0,        "P001-P060",    "individual id; one row = one individual",
  "altitude_group",  "fct",  "-",    0,        "low<mid<high", "ordered altitude factor",
  "sex",             "fct",  "-",    0,        "F, M",         "sex",
  "body_mass_g",     "dbl",  "g",    0,        "110-240",      "body mass",
  "hemoglobin_g_l",  "dbl",  "g/L",  2,        "100-260",      "hemoglobin; NA = hemolysis"
)
dict
R console
# A tibble: 5 × 6
  variable       type  unit  missing allowed_range description                  
  <chr>          <chr> <chr>   <dbl> <chr>         <chr>                        
1 id             chr   -           0 P001-P060     individual id; one row = one…

逐行解释

  • 第 2 行：tribble() 按「转置」的写法建小表——每列以 ~ 开头，可读性最好。
  • hemoglobin 行：missing = 2 与第 2 章 NA 对账；NA = hemolysis 写明缺失的含义。

数据字典要回答三个问题：这个变量是什么（单位、类型）、缺了怎么办（缺失数与含义）、什么值可信（允许范围）。统计单位（个体/批次/时间点）必须写进去。

常见错误

Error in pika$body_mass : $ operator is invalid for atomic vectors

病因：把向量当成了数据框——$ 只能用于列表/数据框。

修复：确认对象类型 class(pika)；列名核对 names(pika)。

预防：读入后先 glimpse()，别凭记忆猜列名。

Error: Can't subset columns that don't exist. Column `body_mass` doesn't exist.

病因：列名拼写错误（少了 _g）。

修复：names(pika) 或 RStudio 补全；报错里会列出最接近的候选名。

预防：列名也走 snake_case；数据字典与列名一一对应。

Error in `[.data.frame`(pika, 1, ) : 重复的行名… / duplicated row names

病因：把 ID 当行名后又有重复 ID——tidy 数据不依赖行名，用列存 ID。

修复：用 pika[pika$id == "P001", ] 按 ID 检索。

预防：tibble 默认不设行名；坚持「ID 是列，不是行名」。

更多同类报错见 R 代码急救室。

统计单位必须在数据字典里写清：本章的 60 是个体数；第 15 章你会看到，同一只个体测 3 次的 36 行仍是 12 个个体。表的形状决定 n 的含义。

metadata_tidy.csv 由脚本从 data-raw/ 生成——不要在 Excel 里直接改它；要改的是脚本和字典。

Individual identity, sex, and altitude group were verified against the sample sheet prior to analysis; each row of the analysis dataset corresponds to one individual (n = 60).

中文：分析前逐项核对个体编号、性别与海拔组；分析数据集每行对应一个个体（n = 60）。

小结

数据框 = 等长向量的集合；tidy = 一行一个体、一列一变量、一表一实验。ID 唯一性用 duplicated()/distinct() 双保险，数据字典逐变量写单位、缺失与范围。
