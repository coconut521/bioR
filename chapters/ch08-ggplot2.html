ggplot2 语法：把科研问题画成图

图不是一个函数画出来的，而是七层语法叠出来的——每一层都能说清「给图加了什么」。

本章科研问题：体重随海拔如何分布？血红蛋白与海拔什么关系？性别会改变这个模式吗？

120–150 MIN前置 ch07数据 pika_physiology.csv交付 fig_explore_mass/hb/sex.svg

学习目标

  • 说出图形语法的七个部件，并解释每一层的作用。
  • 根据问题选择 geom：分布用箱线 + 散点，关系用散点，比较用箱线。
  • 分清 映射（aes() 里）与设定（aes() 外）。
  • 用 facet_wrap() 回答「性别是否改变模式」。
  • 解释为什么小 n 的组间比较不该用柱状图 + 误差线。
  • 用 ggsave() 按 mm 尺寸导出三张交付图。

前置：第 7 章；数据：pika_physiology.csv；交付：fig_explore_mass.svg、fig_explore_hb.svg、fig_explore_sex.svg。

拿到数据的第一件事不是做检验，是看图。三个探索问题对应三张图：分布（体重 × 海拔）、关系（血红蛋白 × 海拔）、分组模式（再加性别分面）。这一章把「画图」翻译成「用七层语法说话」——图层清楚了，图就不需要调参玄学。

1. 图形语法：data → aes → geom

一张 ggplot 的基本句法：ggplot(data, aes(...)) + geom_*()。data 是画什么，aes 是列到视觉通道的映射，geom 是几何形状。图层用 + 叠加——每个 + 后面都是一层可解释的决定。

示例 1：第一张图——体重 × 海拔

data · aes · geom科研必会
library(readr); library(dplyr); library(ggplot2)
pika <- read_csv(here::here("assets/data/pika_physiology.csv"),
                 show_col_types = FALSE)
p <- ggplot(pika, aes(altitude_group, body_mass_g, fill = altitude_group)) +
  geom_boxplot(width = .55, outlier.shape = NA) +
  geom_jitter(width = .12, alpha = .45, size = .7)
class(p)
rlang::as_label(p$mapping$x)
range(pika$body_mass_g)
R console
[1] "ggplot2::ggplot" "ggplot"          "ggplot2::gg"     "S7_object"      
[5] "gg"             
[1] "altitude_group"

逐行解释

  • 第 4 行：data = pika；aes() 把 x 映射到海拔组、y 映射到体重、fill 映射到组。
  • 第 5–6 行：两层 geom：箱线图画 IQR 与中位数，散点画出每个个体——分布和 n 同时可见。
  • 第 7 行：class(p) 确认它是一个 ggplot 对象（还没画，只是说明书）。
  • 第 8–9 行：映射的 x 是 altitude_group；原始体重范围 118–232 g。

常见错误

把 fill = "steelblue" 写进 aes() 里——R 会创建一个常量列「steelblue」并给你一个莫名其妙的离散标度。颜色是设定，放 aes() 外。

2. 为什么不是柱状图：分布藏在均值后面

柱状图 + 误差线只给你两个数：均值和误差。分布的形状、离群值、每组 n——全被藏起来。先算出每组的五个数字，再决定该用什么图。

示例 2：五数概括暴露柱状图的问题

为什么要箱线图图形判断
library(readr); library(dplyr)
pika <- read_csv(here::here("assets/data/pika_physiology.csv"),
                 show_col_types = FALSE)
pika |>
  group_by(altitude_group) |>
  summarise(
    n = n(),
    mean = round(mean(body_mass_g), 1),
    median = round(median(body_mass_g), 1),
    min = round(min(body_mass_g), 1),
    max = round(max(body_mass_g), 1),
    .groups = "drop"
  )
R console
# A tibble: 3 × 6
  altitude_group     n  mean median   min   max
  <chr>          <int> <dbl>  <dbl> <dbl> <dbl>
1 high              20  168.   171.  118   194.
2 low               20  180.   182.  151   215.
3 mid               20  179.   177.  147.  232

逐行解释

  • 输出：三组每组 n = 20，但均值与中位数不一致（high：168 vs 171；mid：179 vs 177）——分布不对称。
  • 范围：三组的最小值 118–151、最大值 194–232 都跨得很开——高海拔组有一个 118 g 的个体，柱状图完全看不见它。
  • 推论：柱状图只能画均值；均值被极端值拉动，分布的重叠也被抹掉。箱线图 + 散点同时给出中位数、IQR、范围与每个个体。

常见错误

「均值柱 + 误差线」配小 n：读者会以为分布是正态的、没有离群值、n 都一样。n = 20/组 时正确做法是箱线 + 散点，图注写 n。

3. 映射与设定：colour = sex 不是 colour = "red"

映射（mapping）把一列数据接到视觉通道上：aes(colour = sex) 生成图例、按性别配色。设定（setting）给一个固定值：colour = "red"。两者写错位置，图的语义就错了。

示例 3：血红蛋白 × 海拔，按性别映射颜色与形状

mapping vs setting科研必会
library(readr); library(ggplot2)
pika <- read_csv(here::here("assets/data/pika_physiology.csv"),
                 show_col_types = FALSE)
p <- ggplot(pika[!is.na(pika$hemoglobin_g_l), ],
            aes(altitude_m, hemoglobin_g_l, colour = sex, shape = sex)) +
  geom_point(size = 1.4, alpha = .8)
length(unique(p$data$altitude_m))
nrow(p$data)
class(p$layers[[1]]$geom)
R console
[1] 3
[1] 58
[1] "GeomPoint" "Geom"      "ggproto"   "gg"

逐行解释

  • 第 3–5 行：先剔除 2 个溶血 NA（否则 ggplot 每次都会警告「removed 2 rows」）；x 用连续海拔、颜色与形状都映射到性别。
  • 第 6 行：海拔只有 3 个取值（3200/4100/5000）——点会排成三条竖线，所以配合轻微抖动或分面更易读。
  • 第 7 行：58 个点 = 60 − 2。
  • 第 8 行：图层类型是 GeomPoint——每个 + 后面就是这样一个图层对象。

常见错误

把连续变量（如体重）映射到 colour 却配了离散色板 → 「Continuous value supplied to discrete scale」。连续变量用 viridis；离散才用 Okabe–Ito。

4. 分面：性别是否改变模式

「性别是否改变海拔与体重的关系」不需要新的 geom——把同一张图按性别拆成两个面板（facet_wrap(~sex)），模式是否一致一眼就能比。

示例 4：facet_wrap 按性别分面

facet_wrap比较模式
library(readr); library(ggplot2)
pika <- read_csv(here::here("assets/data/pika_physiology.csv"),
                 show_col_types = FALSE)
p <- ggplot(pika, aes(altitude_group, body_mass_g, fill = altitude_group)) +
  geom_boxplot(width = .55, outlier.shape = NA) +
  facet_wrap(~sex, nrow = 1)
length(unique(p$data$sex))
class(p$facet)
R console
[1] 2
[1] "FacetWrap" "Facet"     "ggproto"   "gg"

逐行解释

  • 第 6 行：facet_wrap(~sex, nrow = 1) 按性别切两个面板，一行排列；每组的 n 不变（10/组）。
  • 第 7–8 行：确认 2 个水平、分面对象是 FacetWrap。
  • 解读：雌性组间差异更明显，雄性三组更接近——「性别可能修饰海拔效应」，这是第 11 章交互项假设的来源。

常见错误

分面时每个面板用独立的 y 轴范围（scales = "free_y"）——面板间差异被抹平。比较模式时坚持共享标度（默认）。

5. 导出三张探索图

探索图也要有尺寸与主题：ggsave(width, height, units = "mm") 按期刊单栏宽（89 mm）导出。三张图对应三个问题，文件名带语义——这本身就是「图先于检验」的交付证据。

示例 5：三张交付图按 89 mm 导出

ggsave科研必会
library(readr); library(ggplot2)
pika <- read_csv(here::here("assets/data/pika_physiology.csv"),
                 show_col_types = FALSE)
dir.create(here::here("figures"), showWarnings = FALSE)
p_mass <- ggplot(pika, aes(altitude_group, body_mass_g, fill = altitude_group)) +
  geom_boxplot(width = .55, outlier.shape = NA) +
  geom_jitter(width = .12, alpha = .45, size = .7) +
  scale_fill_manual(values = c(low = "#56B4E9", mid = "#E69F00",
                               high = "#0072B2"), guide = "none") +
  labs(x = "Altitude group", y = "Body mass (g)") +
  theme_classic(base_size = 9)
p_hb <- ggplot(pika[!is.na(pika$hemoglobin_g_l), ],
               aes(altitude_m, hemoglobin_g_l, colour = sex)) +
  geom_point(size = 1.4, alpha = .8) +
  labs(x = "Altitude (m)", y = "Haemoglobin (g/L)") +
  theme_classic(base_size = 9)
p_sex <- ggplot(pika, aes(altitude_group, body_mass_g, fill = altitude_group)) +
  geom_boxplot(width = .55, outlier.shape = NA) +
  facet_wrap(~sex, nrow = 1) +
  scale_fill_manual(values = c(low = "#56B4E9", mid = "#E69F00",
                               high = "#0072B2"), guide = "none") +
  labs(x = NULL, y = "Body mass (g)") +
  theme_classic(base_size = 9)
ggsave(here::here("figures/fig_explore_mass.svg"), p_mass,
       width = 89, height = 55, units = "mm")
ggsave(here::here("figures/fig_explore_hb.svg"), p_hb,
       width = 89, height = 55, units = "mm")
ggsave(here::here("figures/fig_explore_sex.svg"), p_sex,
       width = 89, height = 65, units = "mm")
file.exists(here::here(c("figures/fig_explore_mass.svg",
                         "figures/fig_explore_hb.svg",
                         "figures/fig_explore_sex.svg")))
R console

逐行解释

  • 第 6–21 行：三张图的完整说明书——数据、映射、geom、色板、标签、主题。
  • 第 22–27 行：ggsave 按 mm 导出：单栏 89 mm 宽，高度按图的内容选 55/65 mm。
  • 第 28–30 行：三个 TRUE = 三份交付物落盘。

常见错误

只在 RStudio 窗口里截图。投稿要的是矢量文件 + 固定物理尺寸；ggsave 缺 units = "mm" 时默认英寸，89 会变成 2260 mm 的巨图。

科研任务：三张探索图

把本章操作串成 R/08_explore.R，产出三张交付图。

  1. 分布：体重 × 海拔，箱线 + 散点；图注写 n = 20/组。
  2. 关系：血红蛋白 × 海拔，按性别分色 + 分形状；剔除 2 个 NA 并说明。
  3. 模式：体重 × 海拔按性别分面，共享 y 轴。
  4. 导出：三张 SVG 按 89 mm 单栏宽；file.exists() 全部 TRUE。

检查点

  • 每张图都能回答「为什么用这个 geom」——写进图注。
  • 三张图共用同一套配色与字号。
  • 图注含 n、单位与统计说明（误差带/拟合方法）。

常见错误

Error: `mapping` must be created by `aes()`. ℹ Did you use `aes()`?

病因：把映射直接写成了 x = body_mass_g，没包 aes()。

修复：ggplot(pika, aes(x = ..., y = ...))。

预防：只有常量设定才写在 aes() 外。

Error in `geom_boxplot()`: ! stat_boxplot requires the following missing aesthetics: y.

病因：映射里缺 y（或 y 的列名拼错），geom 不知道该画什么。

修复：补 y = body_mass_g；核对列名 names(pika)。

预防：报错会明确列出缺失的 aesthetic——按名字补。

Error: Aesthetics must be either length 1 or the same as the data (60): colour.

病因：在 aes() 里传了一个长度不为 1 的外部向量（比如 colour = c("red","blue")）。

修复：颜色作为设定写在外面，或用列映射 colour = sex。

预防：aes() 里只放列名或长度为 1 的常量。

更多同类报错见 R 代码急救室。

图先于检验。先看图判断方向、重叠与离群值，再选检验（第 11 章）。图必须显示分布与 n，而不是只显示均值——「均值柱 + 误差线」在小 n 时是一种视觉误导。

三张图的代码与 ggsave 尺寸都在 08_explore.R 里；重跑脚本应得到同样尺寸、同样配色、同样文件的图。

Exploratory figures were produced with ggplot2: body mass by altitude group is shown as box plots (IQR, 1.5×IQR whiskers) overlaid with individual points; haemoglobin is plotted against sampling altitude with sex encoded by both colour and shape; the mass–altitude pattern is additionally faceted by sex. All panels share a common scale and report n in the captions.

中文：探索图由 ggplot2 绘制：体重按海拔组用箱线图（IQR、1.5×IQR 须线）并叠加个体点；血红蛋白对采样海拔作图，性别同时用颜色与形状编码；体重–海拔模式再按性别分面。所有面板共享标度，图注报告 n。

小结

ggplot 是七层语法：data / aes / geom / stat / scale / facet / theme，每层一个决定。映射进 aes()，设定在外面；箱线 + 散点显示分布与 n；分面比较模式；ggsave 按 mm 导出矢量图。
