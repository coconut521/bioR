出版级图形：配色、排版、导出与图注

能看 ≠ 能投。单栏 89 mm、字号 7–9 pt、色盲友好、图注独立可读——这一章把探索图升级成 Figure 1。

本章科研问题：怎样把三张探索图拼成一张符合期刊规格、能独立读懂的 Figure 1？

120–150 MIN前置 ch08数据 pika_physiology.csv · Table 1交付 Figure1.pdf · figure1_legend.md

学习目标

  • 用 theme() 把默认主题调成期刊规格（字号、网格、留白）。
  • 用一套 Okabe–Ito 配色贯穿所有面板，并提供形状/线型冗余编码。
  • 用 patchwork 拼双面板并加 A/B 面板标签。
  • 按双栏 183 mm、cairo_pdf 导出矢量 PDF。
  • 写出含 n、统计、误差与软件版本的英文图注。
  • 说清「图注必须能独立读懂」意味着哪些信息不能省。

前置：第 8 章；数据：pika_physiology.csv、ch06 Table 1；交付：Figure1.pdf、figure1_legend.md。

导师把两张图并排放进投稿附件，编辑部退回三条意见：字号太小、配色不友好、图注看不懂。这三条都不是「审美」——它们是可读性规格。这一章把 Figure 1 当成一件工程交付物：尺寸、字体、颜色、标签、图注逐项验收。

1. 主题与字号：把默认图变成期刊图

theme() 是图的「排版层」：字号、网格、边距、图例位置。期刊图的原则：正文 7–9 pt、去掉不必要的网格、留白均匀。theme_bw() / theme_classic() 是起点，再用 theme() 改细节。

示例 1：theme_bw + 三处细节调整

theme科研必会
library(readr); library(ggplot2)
pika <- read_csv(here::here("assets/data/pika_physiology.csv"),
                 show_col_types = FALSE)
p <- ggplot(pika, aes(altitude_group, body_mass_g, fill = altitude_group)) +
  geom_boxplot(width = .55, outlier.shape = NA) +
  labs(x = NULL, y = "Body mass (g)") +
  theme_bw(base_size = 9) +
  theme(panel.grid.minor = element_blank(),
        strip.background = element_blank())
class(p$theme)
p$theme$text$size
R console
[1] "theme"          "ggplot2::theme" "gg"             "S7_object"     
[1] 9

逐行解释

  • 第 6 行：theme_bw(base_size = 9) 一次设定全图基准字号。
  • 第 7–8 行：两处细节：去掉次网格线、去掉分面标题底色。细节按需加，别一次写二十行。
  • 第 9–10 行：确认主题对象与基准字号——9 pt 在 89 mm 单栏上可读。

常见错误

在 RStudio 大窗口里看着舒服就导出：窗口 1200 px 宽、终稿 89 mm，字号缩到原来的 1/4。定图先定物理尺寸，再调字号。

2. 一套配色：让所有面板说同一种语言

配色不是装饰，是编码系统。三条纪律：色盲安全（Okabe–Ito / viridis）、全图一致（同一组永远是同一个颜色）、冗余编码（颜色之外再加形状或线型）。

示例 2：有序因子与色板的对应

scale_fill_manual科研必会
library(readr); library(ggplot2)
pika <- read_csv(here::here("assets/data/pika_physiology.csv"),
                 show_col_types = FALSE)
pika <- pika |>
  dplyr::mutate(altitude_group = factor(altitude_group,
                                        levels = c("low", "mid", "high")))
levels(pika$altitude_group)
pal <- c(low = "#56B4E9", mid = "#E69F00", high = "#0072B2")
scale_fill_manual(values = pal)$palette(3)
R console
[1] "low"  "mid"  "high"
      low       mid      high 
"#56B4E9" "#E69F00" "#0072B2"

逐行解释

  • 第 4–6 行：先把海拔组设为有序因子——图例顺序、色板对应都跟着它走。
  • 第 7 行：low → mid → high。
  • 第 8–9 行：命名向量把颜色绑到水平上；palette(3) 按水平顺序返回三色。命名而不是位置绑定——水平换序也不会错色。

常见错误

用位置向量 values = c("#56B4E9", "#E69F00", "#0072B2") 并以为「颜色对上了」——一旦某组无数据、或水平顺序变化，颜色就错位。永远用具名向量。

3. 拼 Figure 1：patchwork 与面板标签

patchwork 用 + / | 拼图：两个 ggplot 相加就是一张组合图，plot_annotation(tag_levels = "A") 自动加 A/B 标签。投稿图的面板标签是硬要求——审稿人靠它写信。

示例 3：两块面板拼成一张图

patchwork科研必会
library(readr); library(ggplot2); library(patchwork)
pika <- read_csv(here::here("assets/data/pika_physiology.csv"),
                 show_col_types = FALSE)
pika$altitude_group <- factor(pika$altitude_group,
                              levels = c("low", "mid", "high"))
panel_a <- ggplot(pika, aes(altitude_group, body_mass_g, fill = altitude_group)) +
  geom_boxplot(width = .55, outlier.shape = NA) +
  theme_classic(base_size = 8)
panel_b <- ggplot(pika[!is.na(pika$hemoglobin_g_l), ],
                  aes(altitude_m, hemoglobin_g_l, colour = sex)) +
  geom_point(size = 1.2) +
  theme_classic(base_size = 8)
fig <- wrap_plots(panel_a, panel_b, nrow = 1) +
  plot_annotation(tag_levels = "A")
class(fig)
R console
[1] "patchwork"       "ggplot2::ggplot" "ggplot"          "ggplot2::gg"    
[5] "S7_object"       "gg"

逐行解释

  • 第 6–13 行：两块面板各自完整（自己的 data/aes/geom/theme），字号同为 8 pt。
  • 第 14–15 行：wrap_plots(nrow = 1) 并排；tag_levels = "A" 生成 A、B。
  • 第 16 行：class(fig) 是 patchwork 对象——它仍然是 ggplot 家族，可以继续 & theme() 统一改主题。

常见错误

两块面板用了不同色板/字号，拼起来像两张图硬贴在一起。先统一，再拼。拼图不是 PS，是同一套代码的输出。

4. 导出：183 mm、cairo_pdf、矢量

导出规格由期刊决定：单栏 89 mm、双栏 183 mm、PDF/SVG 矢量、字体嵌入。cairo_pdf 会把字体嵌进 PDF——这是「编辑部打开不跑版」的前提。

示例 4：导出 183 × 105 mm 的 PDF

ggsave · cairo_pdf科研必会
library(readr); library(ggplot2); library(patchwork); library(svglite)
pika <- read_csv(here::here("assets/data/pika_physiology.csv"),
                 show_col_types = FALSE)
pika$altitude_group <- factor(pika$altitude_group,
                              levels = c("low", "mid", "high"))
panel_a <- ggplot(pika, aes(altitude_group, body_mass_g, fill = altitude_group)) +
  geom_boxplot(width = .55, outlier.shape = NA) +
  scale_fill_manual(values = c(low = "#56B4E9", mid = "#E69F00",
                               high = "#0072B2"), guide = "none") +
  labs(x = NULL, y = "Body mass (g)") +
  theme_classic(base_size = 8)
panel_b <- ggplot(pika[!is.na(pika$hemoglobin_g_l), ],
                  aes(altitude_m, hemoglobin_g_l, colour = sex)) +
  geom_point(size = 1.2) +
  labs(x = "Altitude (m)", y = "Haemoglobin (g/L)") +
  theme_classic(base_size = 8)
fig <- wrap_plots(panel_a, panel_b, nrow = 1) +
  plot_annotation(tag_levels = "A")
dir.create(here::here("figures"), showWarnings = FALSE)
ggsave(here::here("figures/Figure1.pdf"), fig,
       width = 183, height = 105, units = "mm",
       device = cairo_pdf)
file.exists(here::here("figures/Figure1.pdf"))
R console
[1] TRUE

逐行解释

  • 第 6–17 行：两块面板共用命名色板与 8 pt 字号。
  • 第 18–19 行：拼图 + A/B 标签。
  • 第 21–23 行：width = 183、units = "mm"、device = cairo_pdf——双栏宽、字体嵌入。
  • 第 24 行：TRUE = 文件落盘。

常见错误

导出 PNG 交稿（400 dpi 也不满足矢量要求），或忘记 units 得到 183 英寸的巨图。投稿前按期刊 Author Guidelines 核对三项：尺寸、格式、字体。

5. 图注：能独立读懂的说明书

图注（figure legend）不是图的标题，是图的自解释文档：n、统计与误差定义、配色含义、软件版本。标准是：把图注单独抽出来，读者也能知道每个面板画了什么、每个点代表什么。

示例 5：写 figure1_legend.md

图注模板科研必会
library(readr)
legend <- c(
  "Figure 1. Body mass and haemoglobin across altitude in plateau pikas.",
  "(A) Body mass by altitude group (low, mid, high; n = 20 per group). Boxes show the",
  "interquartile range (IQR) with the median as a horizontal line; whiskers extend to",
  "1.5 x IQR; individual animals are shown as points.",
  "(B) Haemoglobin concentration versus sampling altitude (n = 58; two haemolysis",
  "samples excluded). Sex is encoded by both colour and shape. Lines are ordinary",
  "least-squares fits shown for trend only; sampling altitudes were 3200, 4100 and",
  "5000 m.",
  "Data are simulated teaching data (fixed seed 20261027) and do not represent real",
  "animals. Colour palette: Okabe-Ito (colour-blind safe)."
)
dir.create(here::here("figures"), showWarnings = FALSE)
writeLines(legend, here::here("figures/figure1_legend.md"))
length(readLines(here::here("figures/figure1_legend.md")))
R console
[1] 10

逐行解释

  • 第 1 行：标题句——一句话说清这张图是什么。
  • A 段：n、箱线图定义（IQR/中位数/须）、点代表个体。
  • B 段：n = 58 与剔除原因（溶血）、颜色+形状编码、拟合方法与用途、采样海拔。
  • 末段：数据性质（模拟、固定种子）与色板——诚实与可复现。

常见错误

图注只写「图 1 体重与血红蛋白」——n 没写、误差线含义没写、面板 A/B 没解释。审稿人只能猜；猜错的代价是返修。

科研任务：Figure1.pdf 与 figure1_legend.md

把本章操作串成 R/09_figure1.R，产出两份交付物。

  1. 拼图：A 分布、B 关系（C 交互面板留位）；统一色板与字号；A/B 标签。
  2. 导出：183 × 105 mm、cairo_pdf、文件名 Figure1.pdf。
  3. 图注：英文 legend 含 n、箱线图定义、剔除说明、拟合方法与数据性质。
  4. 自检：把 PDF 缩到 100% 打印——字号 ≥ 7 pt、颜色可辨、面板标签清楚。

检查点

  • 图注单独发给同学，他能说出 A/B 各画什么、n 是多少。
  • PDF 里字体已嵌入（不是「字体缺失」的方块）。
  • 两面板同色板：low 永远同一种蓝。

常见错误

Error in grid.Call.graphics(C_text, as.graphicsAnnot(x$label), x$x, x$y, : invalid font type

病因：主题里指定了系统不存在（或未正确注册）的字体族，导出 PDF 时渲染失败。

修复：用默认字体或 showtext/sysfonts 注册后再用；导出用 cairo_pdf。

预防：图里只用一种字体族；换机器前先渲染测试。

Warning: Removed 2 rows containing missing values (geom_point).

病因：血红蛋白的 2 个 NA 进了绘图数据；ggplot 静默移除并警告。

修复：绘图前显式 filter(!is.na(hemoglobin_g_l))，并在图注写明剔除原因。

预防：看到 Removed N rows 就当报错处理——数字要能对上（60 → 58）。

Error: Discrete value supplied to continuous scale

病因：y 或 x 映射到了字符/因子列，却用了连续标度（或反之）。

修复：核对列类型；因子用离散标度，数值用连续标度。

预防：画图前 glimpse() 一眼类型（第 3 章的习惯）。

更多同类报错见 R 代码急救室。

图注必须能独立读懂。误差线写清是 SD、SEM 还是 95% CI；统计标注写清检验与 p 值；n 写进图注。图注是论文里唯一「图和文字共用的文档」——它错了，图和结论一起错。

Figure1.pdf 与 figure1_legend.md 都由 09_figure1.R 生成；改图只改脚本，不在 Illustrator 里手调（手调的部分下次重跑就没了）。

Figure 1 was assembled from two ggplot2 panels with patchwork, using a single colour-blind-safe palette (Okabe–Ito) and a common 8-pt type size; panel tags A and B were added automatically. The figure was exported as a 183-mm-wide vector PDF with embedded fonts, and the legend reports n, box-plot definitions, exclusion reasons and fitting methods.

中文：Figure 1 由两个 ggplot2 面板经 patchwork 拼合，全图使用同一套色盲安全色板（Okabe–Ito）与 8 pt 字号，并自动添加 A/B 面板标签；以 183 mm 宽矢量 PDF（字体嵌入）导出；图注报告 n、箱线图定义、剔除原因与拟合方法。

小结

期刊图 = 规格工程：物理尺寸先定（89/183 mm）、字号 7–9 pt、一套命名色板 + 形状冗余、patchwork 拼图加标签、cairo_pdf 导出、图注独立可读。每一步都由脚本生成，可重跑。
