描述统计与分布：先看数据，再做检验

血红蛋白右偏、体重有三个离群值——不做这一步就直接 t 检验，是在赌前提成立。

本章科研问题：这些数据长什么样？直接做 t 检验/ANOVA 合适吗？

90–120 MIN前置 ch09数据 pika_physiology.csv交付 02_descriptive.R · fig_distributions.svg

学习目标

  • 用 mean()/sd()/median()/IQR()/quantile() 描述一个变量。
  • 用直方图 + 密度曲线判断偏态，而不是只看均值。
  • 理解正态性检验的边界（n、尾部、机械决策的危险）。
  • 用预定义的 IQR 规则标记离群值（标记 ≠ 删除）。
  • 判断是否需要 log 变换，并把决定写进分析记录。
  • 产出分布面板 fig_distributions.svg。

前置：第 9 章；数据：pika_physiology.csv；交付：02_descriptive.R、fig_distributions.svg。

「直接做检验」是新手最常见的捷径，也是前提被违反的最常见来源。在 ch11 的 t 检验之前，这一章把三件事做完：描述（均值±SD 还是中位数(IQR)）、看形状（偏态与离群值）、做决定（要不要变换、要不要标记离群值）。每个决定都写在脚本注释里——这是「先于结果」的证据。

1. 描述统计：均值、SD、中位数与 IQR

连续变量的描述统计只有两类组合：均值 ± SD（近似对称）与中位数 (IQR)（偏态或有离群值）。两者都报也无妨，但必须说清为什么选哪个。Table 1 里已经见过这个选择——现在把它做成逐组的小表。

示例 1：三组体重与血红蛋白的描述统计

mean · sd · median · IQR科研必会
library(readr); library(dplyr)
pika <- read_csv(here::here("assets/data/pika_physiology.csv"),
                 show_col_types = FALSE)
pika |>
  group_by(altitude_group) |>
  summarise(n = n(),
            mean = round(mean(body_mass_g), 1),
            sd = round(sd(body_mass_g), 1),
            median = round(median(body_mass_g), 1),
            iqr = round(IQR(body_mass_g), 1),
            .groups = "drop")
hb <- pika$hemoglobin_g_l
c(mean = round(mean(hb, na.rm = TRUE), 1),
  median = round(median(hb, na.rm = TRUE), 1),
  sd = round(sd(hb, na.rm = TRUE), 1),
  iqr = round(IQR(hb, na.rm = TRUE), 1))
R console

逐行解释

  • 第 4–10 行：每组五个数字。high 组均值 168.3 < 中位数 171.1——左尾被 118 g 拉低，典型的偏态信号。
  • 第 11–14 行：血红蛋白均值 164.3 > 中位数 162.8，右偏；IQR 15.5 与 SD 15.9 接近。
  • 判断：体重用中位数(IQR) 描述更稳；血红蛋白虽然右偏，但幅度不大（均值-中位数 1.5 g/L）。

常见错误

偏态数据报 mean ± SD：SD 被长尾撑大，读者会以为分布对称。均值与中位数差得远 = 偏态信号，这时优先中位数(IQR)，或同时报并说明。

2. 分布形状：直方图、密度与正态性检验的边界

形状要靠图看：直方图 + 密度曲线给出尾部与峰的形状。正态性检验（Shapiro–Wilk）只是辅助——它回答「偏离正态是否可检测」，不回答「偏离是否影响检验」。n 越大，越容易显著。

示例 2：三个 Shapiro 检验的对照

shapiro.test前提判断
library(readr)
pika <- read_csv(here::here("assets/data/pika_physiology.csv"),
                 show_col_types = FALSE)
round(shapiro.test(pika$body_mass_g)$p.value, 3)
round(shapiro.test(pika$hemoglobin_g_l)$p.value, 3)
round(shapiro.test(log(pika$hemoglobin_g_l))$p.value, 3)
R console
[1] 0.011
[1] 0.152
[1] 0.565

逐行解释

  • 第 4 行：体重 p = 0.011——有证据偏离正态（三个离群值 + 偏态）。
  • 第 5 行：血红蛋白 p = 0.152——没有检测到偏离，尽管直方图右尾略长。小样本 + 轻偏态时检验不敏感。
  • 第 6 行：log 后 p = 0.565——更「正态」了，但原始数据本来也没被拒绝。

常见错误

「p < 0.05 就必须变换 / 必须用非参数检验」——机械决策。要看偏离的幅度与影响：t 检验对轻偏态稳健；n 大时 Shapiro 几乎必然显著。检验是参考，图与设计才是决策依据。

3. 离群值：用规则标记，而不是删除

离群值的正确动作是标记 + 报告，不是删除。规则必须事先定义：本章用 1.5×IQR 规则（箱线图同款），把标记写进数据与图注。删除只在「有独立的测量错误证据」时才允许。

示例 3：1.5×IQR 规则标出 3 个个体

quantile · IQR科研必会
library(readr); library(dplyr)
pika <- read_csv(here::here("assets/data/pika_physiology.csv"),
                 show_col_types = FALSE)
q <- quantile(pika$body_mass_g, c(.25, .75))
iqr <- IQR(pika$body_mass_g)
lo <- unname(q[1] - 1.5 * iqr)
hi <- unname(q[2] + 1.5 * iqr)
c(lower = round(lo, 1), upper = round(hi, 1))
pika |>
  filter(body_mass_g < lo | body_mass_g > hi) |>
  select(id, altitude_group, body_mass_g)
R console
lower upper 
146.5 204.3 
# A tibble: 3 × 3
  id    altitude_group body_mass_g
  <chr> <chr>                <dbl>
1 P017  low                   215.
2 P023  mid                   232 
3 P048  high                  118

逐行解释

  • 第 4–7 行：IQR = Q3 − Q1；上下界 = Q1 − 1.5×IQR、Q3 + 1.5×IQR。本数据 [146.5, 204.3]。
  • 第 8 行：三个被标记者：P017（215）、P023（232）、P048（118 g）——分别来自低、中、高海拔组。
  • 处置：标记保留在数据里，图注写「橙点为超出 1.5×IQR 的个体，未删除」；敏感性分析可再跑一遍去掉这 3 行的结果（第 13 章）。

常见错误

先做检验、发现不显著、再回来删离群值重跑——这是 p 值钓鱼。规则必须在看结果之前写下并写进脚本。

4. 变换：log 什么时候用

log 变换压缩右侧长尾，适用于乘性误差与右偏数据（浓度、计数、时间）。判断依据是图与背景知识，不是「Shapiro 显著就 log」。变换要在看组间结果之前决定，并在方法与图注里写明。

示例 4：log 前后的均值与 SD

log前提处理
library(readr); library(dplyr)
pika <- read_csv(here::here("assets/data/pika_physiology.csv"),
                 show_col_types = FALSE)
hb <- pika$hemoglobin_g_l
c(raw_mean = round(mean(hb, na.rm = TRUE), 1),
  raw_sd = round(sd(hb, na.rm = TRUE), 1))
c(log_mean = round(mean(log(hb), na.rm = TRUE), 2),
  log_sd = round(sd(log(hb), na.rm = TRUE), 2))
round(shapiro.test(log(hb))$p.value, 3)
R console
raw_mean   raw_sd 
   164.3     15.9 
log_mean   log_sd 
     5.1      0.1 
[1] 0.565

逐行解释

  • 第 4–5 行：原始尺度：均值 164.3、SD 15.9 g/L。
  • 第 6–7 行：log 尺度：均值 5.10、SD 0.10（log g/L）——数值变小但信息未丢。
  • 第 8 行：log 后 Shapiro p = 0.565。注意：原始数据 p = 0.152 本来也没拒绝——本例不需要 log。
  • 决定：写进脚本注释：「血红蛋白轻右偏，Shapiro 未拒绝；保留原始尺度，报告 mean ± SD；log 作为敏感性分析」。

常见错误

报告 log 后的均值（5.10）却不说明是 log 尺度——读者以为是 g/L。变换后的结果要么 back-transform 再报告，要么明确标注单位。

5. 分布面板交付

把前面的判断做成一张两面板的分布图：A 直方图 + 密度（看形状），B 箱线 + 个体点（看离群值）。这正是图 10.1 的生成代码——与站点图同源。

示例 5：fig_distributions.svg

patchwork · ggsave科研必会
library(readr); library(dplyr); library(ggplot2); library(patchwork)
pika <- read_csv(here::here("assets/data/pika_physiology.csv"),
                 show_col_types = FALSE)
dir.create(here::here("figures"), showWarnings = FALSE)
hb <- pika$hemoglobin_g_l[!is.na(pika$hemoglobin_g_l)]
q <- quantile(pika$body_mass_g, c(.25, .75))
lo <- q[1] - 1.5 * IQR(pika$body_mass_g)
hi <- q[2] + 1.5 * IQR(pika$body_mass_g)
pika$outlier <- ifelse(pika$body_mass_g < lo | pika$body_mass_g > hi,
                       "IQR outlier", "within 1.5 x IQR")
panel_a <- ggplot(data.frame(hb = hb), aes(hb)) +
  geom_histogram(aes(y = after_stat(density)), binwidth = 5, boundary = 0,
                 fill = "#56B4E9", colour = "white") +
  geom_density(colour = "#0072B2") +
  labs(x = "Haemoglobin (g/L)", y = "Density") +
  theme_classic(base_size = 8)
panel_b <- ggplot(pika, aes("Body mass", body_mass_g)) +
  geom_boxplot(width = .35, outlier.shape = NA) +
  geom_jitter(aes(colour = outlier), width = .08, size = 1) +
  scale_colour_manual(values = c("IQR outlier" = "#D55E00",
                                 "within 1.5 x IQR" = "#4D4D4D")) +
  labs(x = NULL, y = "Body mass (g)", colour = NULL) +
  theme_classic(base_size = 8)
fig <- wrap_plots(panel_a, panel_b, nrow = 1) +
  plot_annotation(tag_levels = "A")
ggsave(here::here("figures/fig_distributions.svg"), fig,
       width = 183, height = 70, units = "mm")
file.exists(here::here("figures/fig_distributions.svg"))

逐行解释

  • 第 5–9 行：剔除 NA、按 IQR 规则标记离群值（不删除）。
  • 第 10–17 行：面板 A：直方图（密度归一）+ 密度曲线——形状一眼可见。

常见错误

把标记的离群值直接从图里剔除——图就说谎了。橙色点保留在图上，图注解释规则与处理方式；敏感性分析另开一节。

常见错误

Error in shapiro.test(x) : sample size must be between 3 and 5000

病因：样本量超出 Shapiro–Wilk 的适用范围（< 3 或 > 5000）。

修复：小样本看 QQ 图与背景知识；大样本改用图形判断，别用检验的 p 值。

预防：正态性用「图 + 检验 + n」三件套，不迷信单一 p。

Error in quantile.default(x, c(0.25, 0.75)) : missing values and NaN's not allowed if 'na.rm' is FALSE

病因：血红蛋白含 NA，直接算分位数报错。

修复：quantile(x, probs, na.rm = TRUE)，或先 filter 掉 NA 并记录。

预防：描述统计前先 sum(is.na())，决定「剔除并记录」而不是随手加 na.rm。

Warning in mean.default(hb) : argument is not numeric or logical: returning NA

病因：对字符列调 mean()（读入时某一列被当成 chr，比如带单位的「155 g/L」）。

修复：parse_number() 清洗后转数值；核对列类型。

预防：导入后 glimpse() 查类型（第 3 章）。

更多同类报错见 R 代码急救室。

分布形状决定描述统计与检验。偏态或有离群值 → 中位数(IQR) 描述、Wilcoxon 或置换检验；近似对称 → mean±SD、t/ANOVA。变换与离群值处理必须先于看组间结果决定，并记录在脚本与图注里。

离群值规则、变换决定、描述统计全部写在 02_descriptive.R；图 10.1 由同一脚本生成——重跑即复现，不靠手改表格。

Continuous variables are reported as mean ± SD with median (IQR) where distributions were skewed. Outliers were defined a priori by the 1.5×IQR rule and flagged (not removed) in all analyses. Normality was assessed graphically with histograms and density curves and supplemented by Shapiro–Wilk tests; no transformation was applied to haemoglobin.

中文：连续变量报告均值±SD，偏态变量同时报告中位数(IQR)；离群值按预先定义的 1.5×IQR 规则标记（未删除）；正态性以直方图与密度曲线评估，并以 Shapiro–Wilk 检验辅助；血红蛋白未做变换。

小结

先描述再检验：均值±SD 或中位数(IQR) 由分布形状决定；直方图 + 密度看形状，Shapiro 只作参考；1.5×IQR 规则标记离群值但保留；log 变换先决定后记录。分布面板与决定一起交付。
