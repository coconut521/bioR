两组比较：t 检验与 Wilcoxon

p = 0.048 不是「显著优于」——它只是「在 α = 0.05 的规则下勉强过线」。效应量和 CI 才告诉你差异有多大。

本章科研问题：低氧/性别等两组之间，差异有多大？能否排除「没有差异」？

120–150 MIN前置 ch10数据 pika_physiology · pika_repeated交付 stats_two_group.csv · methods_two_group.md

学习目标

  • 先写设计（独立/配对、双侧、α）再选检验。
  • 用 Welch t 检验比较两组，并知道为什么默认不用 Student。
  • 用 broom::tidy() 取均值差与 95% CI，用 effectsize 取 Cohen's d。
  • 用配对 t 检验处理同一批个体的前后比较。
  • 说出「不显著 ≠ 无差异」与「p 值小 ≠ 效应大」。
  • 产出含 CI 与效应量的 stats_two_group.csv 与方法文段。

前置：第 10 章；数据：pika_physiology.csv、pika_repeated.csv；交付：stats_two_group.csv、methods_two_group.md。

两组比较是科研里出现频率最高的统计动作：处理 vs 对照、雌 vs 雄、前 vs 后。问题不在「会不会跑 t.test」，而在三件先于代码的事：设计是独立还是配对？方差不齐怎么办？要看的是差异大小还是一张 p 值？这一章把这三个决定写进脚本，然后让数据说话。

1. 独立两组：Welch t 检验

独立两组（不同个体）的比较默认用 Welch t 检验（var.equal = FALSE）：它不假设两组方差相等，代价只是自由度略小。R 的 t.test() 默认就是 Welch——你不需要「升级」，只需要知道自己在用哪个。

示例 1：雌雄体重的 Welch 比较

t.test · tidy科研必会
library(readr); library(dplyr); library(broom)
pika <- read_csv(here::here("assets/data/pika_physiology.csv"),
                 show_col_types = FALSE)
res <- t.test(body_mass_g ~ sex, data = pika)
tidy(res) |> select(estimate1, estimate2, estimate, conf.low, conf.high, p.value)
R console
# A tibble: 1 × 6
  estimate1 estimate2 estimate conf.low conf.high p.value
      <dbl>     <dbl>    <dbl>    <dbl>     <dbl>   <dbl>
1      171.      180.    -8.64    -17.2   -0.0824  0.0479

逐行解释

  • 第 4 行：公式接口 y ~ group；默认 Welch（不等方差）。
  • 第 5 行：tidy() 把 htest 压成一行：两组均值 171.0 / 179.7、均值差 −8.6 g、95% CI [−17.2, −0.08]、p = 0.048。
  • 解读：CI 几乎贴着 0（下界 −0.08），p 擦线。差异「可能很小、也可能不小」——这正是必须报 CI 的原因。

常见错误

把 p = 0.048 写成「显著优于」并下生物结论。p 只说明「在 α = 0.05 规则下可以拒绝零假设」；差异多大由 CI 与效应量说话。

2. 假设检查：方差齐性与正态性

Welch 不需要方差齐性，但检查它有两个用处：决定用哪个 t（方差差得远就别用 Student）、以及在方法里说明。正态性检查（ch10）同理——辅助判断，不是机械开关。

示例 2：方差比 3.2，Student 与 Welch 的 p 差多少

var.test前提判断
library(readr); library(dplyr); library(broom)
pika <- read_csv(here::here("assets/data/pika_physiology.csv"),
                 show_col_types = FALSE)
suppressMessages(tidy(var.test(body_mass_g ~ sex, data = pika))) |>
  select(estimate, p.value)
c(student = round(tidy(t.test(body_mass_g ~ sex, data = pika,
                              var.equal = TRUE))$p.value, 4),
  welch = round(tidy(t.test(body_mass_g ~ sex, data = pika,
                            var.equal = FALSE))$p.value, 4))
R console
# A tibble: 1 × 2
  estimate p.value
     <dbl>   <dbl>
1     3.20 0.00246
student   welch 
 0.0467  0.0479

逐行解释

  • 第 4–5 行：方差比 3.20（雌性 SD 20.3 vs 雄性 11.3），p = 0.0025——方差不齐的证据很强。
  • 第 6–9 行：具名向量并列 Student（0.0467）与 Welch（0.0479）的 p。本例两者接近（n 相等时差别小），但方差严重不齐 + n 不等时 Student 会给出错误的小 p。
  • 决定：方法里写「Welch t-test（不等方差）」——这是默认且稳健的选择。

常见错误

看正态性检验决定 t 还是 Wilcoxon、看方差检验决定 Student 还是 Welch——把两个检验当「开关」是机械决策。前提检查的产出是一句方法学说明 + 一个稳健选择，不是自动流程。

3. 效应量与 CI：差异到底多大

p 值回答「能不能排除零」，效应量回答「差多少」。Cohen's d 把均值差标准化（除以合并 SD），并给出 95% CI——这是能进论文摘要的数字。

示例 3：Cohen's d = −0.52（95% CI −1.04 至 −0.01）

effectsize科研必会
library(readr); library(effectsize)
pika <- read_csv(here::here("assets/data/pika_physiology.csv"),
                 show_col_types = FALSE)
d <- cohens_d(body_mass_g ~ sex, data = pika)
round(d$Cohens_d, 2)
round(d$CI_low, 2)
round(d$CI_high, 2)
R console
[1] -0.52
[1] -1.04
[1] -0.01

逐行解释

  • 第 4 行：cohens_d() 计算标准化均值差（公式接口，与 t.test 一致）。
  • 第 5–7 行：d = −0.52（中等效应）；CI [−1.04, −0.01]——下界跨过 −1（大效应），上界几乎为 0。
  • 解读：效应「中等」但不确定；这个 CI 宽度主要来自雌性组的大 SD（20.3）。

常见错误

只报 p 不报效应量。审稿人会问「差异有生物意义吗」——d = 0.52 与 d = 0.05 可以有同样的 p（只要 n 够大）。p 与效应量必须成对报告。

4. 配对设计：同一批个体的前后比较

配对设计（同一批个体测两次）必须用配对检验：先算每个个体的差值，再对差值做单样本检验。把配对数据当独立两组，会低估方差、做小 p——这是伪重复的近亲。

示例 4：对照组的 T0 vs T28（配对）

paired t · Wilcoxon科研必会
library(readr); library(dplyr); library(tidyr); library(broom)
rep <- read_csv(here::here("assets/data/pika_repeated.csv"),
                show_col_types = FALSE)
wide <- rep |>
  filter(treatment == "control") |>
  select(id, timepoint, body_mass_g) |>
  pivot_wider(names_from = timepoint, values_from = body_mass_g)
paired_t <- t.test(wide$T28, wide$T0, paired = TRUE)
tidy(paired_t) |> select(estimate, conf.low, conf.high, p.value)
wilcox.test(wide$T28, wide$T0, paired = TRUE)$p.value
R console
# A tibble: 1 × 4
  estimate conf.low conf.high p.value
     <dbl>    <dbl>     <dbl>   <dbl>
1     2.53    -5.35      10.4   0.446
[1] 0.4375

逐行解释

  • 第 6–9 行：宽表化后每个 id 一行（T0、T14、T28 各一列）——配对检验的标准形状。
  • 第 10–11 行：配对 t：差值均值 +2.53 g，CI [−5.35, 10.4]，p = 0.446——没有证据表明对照组 28 天内体重变化。
  • 第 12 行：Wilcoxon 符号秩 p = 0.4375——与 t 结论一致（差值近似对称时两者接近）。

常见错误

把 36 行（12 id × 3 时间点）当 36 个独立个体做两组 t 检验——n 虚增 3 倍。先看设计（配对？重复？）再选检验。

5. 端到端：stats_two_group.csv 与方法文段

把前面三个比较整理成一张机器可读的结果表 + 一段方法学文字。结果表的三列固定：比较、estimate、95% CI、p；效应量单独一行。

示例 5：结果表与方法文段落盘

端到端科研必会
library(readr); library(dplyr); library(tidyr); library(broom); library(effectsize)
pika <- read_csv(here::here("assets/data/pika_physiology.csv"),
                 show_col_types = FALSE)
rep <- read_csv(here::here("assets/data/pika_repeated.csv"),
                show_col_types = FALSE)
dir.create(here::here("data"), showWarnings = FALSE)
ind <- tidy(t.test(body_mass_g ~ sex, data = pika, var.equal = FALSE))
d <- cohens_d(body_mass_g ~ sex, data = pika)
wide <- rep |>
  filter(treatment == "control") |>
  select(id, timepoint, body_mass_g) |>
  pivot_wider(names_from = timepoint, values_from = body_mass_g)
pt <- tidy(t.test(wide$T28, wide$T0, paired = TRUE))
res <- tibble(
  comparison = c("mass ~ sex (Welch)", "mass ~ sex (Cohen's d)",
                 "control T0 vs T28 (paired)"),
  estimate = c(round(ind$estimate, 1), round(d$Cohens_d, 2), round(pt$estimate, 1)),
  conf_low = c(round(ind$conf.low, 1), round(d$CI_low, 2), round(pt$conf.low, 1)),
  conf_high = c(round(ind$conf.high, 1), round(d$CI_high, 2), round(pt$conf.high, 1)),
  p_value = c(signif(ind$p.value, 3), NA, signif(pt$p.value, 3)))
write_csv(res, here::here("data/stats_two_group.csv"))
methods <- c(
  "# Two-group comparisons",
  "",
  "- Design: independent groups (sex) and paired visits (control T0 vs T28); two-sided tests, alpha = 0.05.",
  "- Independent comparison: Welch t-test (unequal variances not assumed).",
  "- Effect size: Cohen's d with 95% CI.",
  "- Paired comparison: paired t-test; Wilcoxon signed-rank as sensitivity analysis.",
  "- Software: R 4.5.2; broom/effectsize for tidying."
)
writeLines(methods, here::here("data/methods_two_group.md"))
file.exists(here::here(c("data/stats_two_group.csv",
                         "data/methods_two_group.md")))
R console
[1] TRUE TRUE

逐行解释

  • 第 7–11 行：三个比较的原始结果（Welch t、Cohen's d、配对 t）。
  • 第 12–17 行：拼成统一结果表：比较名、estimate、CI 两列、p 值（d 行的 p 留 NA——效应量本身不产生 p）。
  • 第 18–24 行：方法文段——设计、检验、效应量、敏感性分析、软件版本。
  • 第 25 行：两份交付物 TRUE TRUE。

常见错误

结果表只有 p 值一列。审稿人要的是「差异 + 不确定性」：estimate 与 95% CI 必须在表里。

  • 每个比较都同时有 estimate 与 95% CI。
  • 方法文段提到 Welch 与双侧检验。
  • 配对比较只用了 12 个个体（不是 36 行）。

常见错误

Error in t.test.formula(body_mass_g ~ sex, data = pika) : grouping factor must have exactly 2 levels

病因：公式接口的分组列有 3 个及以上水平（比如把 altitude_group 当分组）。

修复：两组比较先 filter 到两个水平；多组用 ANOVA（第 12 章）。

预防：公式接口只服务两组；多组问题在 ch12 解决。

Error in t.test.default(x = wide$T28, y = wide$T0) : not enough 'y' observations

病因：某一组观测不足 2 个（filter 条件写错、或 id 匹配失败导致空组）。

修复：检查 n；配对比较确认每个 id 两个时间点都有值。

预防：检验前先 count() 两组样本量。

Error in wilcox.test.default(x, y) : 'x' must be numeric

病因：传入了字符列（如带单位的 "155 g/L"）或因读取错位变成 chr。

修复：parse_number() 清洗；glimpse() 核对类型。

预防：导入后立即检查类型（第 3 章的规矩）。

更多同类报错见 R 代码急救室。

先设计后检验；效应量 + CI 比 p 值更重要；不显著 ≠ 无差异。本例配对比较 p = 0.446，CI [−5.4, 10.4] g——「没有证据表明变化」不等于「证明没有变化」。报告要写「no evidence of a difference」，而不是「no difference」。

设计、检验选择、效应量与结果表全在 11_two_group.R；换数据只需重跑，方法文段随代码更新。

Body mass was compared between sexes using a two-sided Welch t-test (unequal variances not assumed), reporting the mean difference with its 95% confidence interval and Cohen's d. Within the control group, body mass at T0 and T28 was compared with a paired t-test, with a Wilcoxon signed-rank test as a sensitivity analysis. Analyses used R 4.5.2.

中文：雌雄体重采用双侧 Welch t 检验（不假设方差齐性），报告均值差、95% CI 与 Cohen's d；对照组 T0 与 T28 采用配对 t 检验，并以 Wilcoxon 符号秩检验作敏感性分析。分析使用 R 4.5.2。

小结

两组比较先写设计（独立/配对、双侧、α），默认 Welch；用 tidy 取 estimate 与 CI，用 effectsize 取 d；配对数据必须配对检验；结果表与 p 值并列 CI；「不显著」只说没有证据。
