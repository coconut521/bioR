多组比较与方差分析：ANOVA 与事后检验

总体 F 显著，不等于任意两组显著——这一章最重要的两个数字是交互 p 与 Tukey 校正后的 p。

本章科研问题：三个海拔的体重差异是否真实？性别会修饰这个差异吗？

120–150 MIN前置 ch11数据 pika_physiology.csv交付 stats_anova.csv · fig_anova_letters.svg

学习目标

  • 用 aov() + summary() 读方差分析表（df、F、p）。
  • 拟合双因素模型（altitude_group * sex），判断交互是否显著。
  • 知道交互优先于主效应：先看交互，再解释主效应。
  • 用 car::leveneTest() 与 kruskal.test() 做前提与稳健性检查。
  • 用 TukeyHSD() / emmeans 事后比较并理解校正后的 p。
  • 读懂并生成紧凑字母标记图 fig_anova_letters.svg。

前置：第 11 章；数据：pika_physiology.csv；交付：stats_anova.csv、fig_anova_letters.svg。

三组比较最容易犯的错是「两两 t 检验」：三次检验把 α 从 5% 堆到约 14%。ANOVA 先回答「有没有任何组间差异」，事后比较再回答「哪几对」。本章还有一个更重要的判断：交互。如果性别改变了海拔效应，主效应就不能单独解释——哪怕主效应显著。

1. 三组比较：单因素 ANOVA

aov() 拟合线性模型，summary() 给出方差分析表：组间平方和、组内（残差）平方和、F 与 p。F = 组间均方 / 组内均方——「组间差异相对于组内波动有多大」。

示例 1：单因素 ANOVA（体重 ~ 海拔组）

aov · anova科研必会
library(readr); library(dplyr)
pika <- read_csv(here::here("assets/data/pika_physiology.csv"),
                 show_col_types = FALSE)
pika$altitude_group <- factor(pika$altitude_group,
                              levels = c("low", "mid", "high"))
m1 <- aov(body_mass_g ~ altitude_group, data = pika)
summary(m1)
R console
               Df Sum Sq Mean Sq F value Pr(>F)  
altitude_group  2   1816   908.1   3.449 0.0385 *
Residuals      57  15006   263.3                 
---
Signif. codes:  0 '***' 0.001 '**' 0.01 '*' 0.05 '.' 0.1 ' ' 1

逐行解释

  • 第 6 行：aov 公式接口；分类变量必须是因子（有序因子不影响检验，但影响图）。
  • 第 7 行：方差分析表：F(2, 57) = 3.45，p = 0.039——至少有一组不同。
  • 读表：组间自由度 = 组数 − 1 = 2；残差自由度 = 60 − 3 = 57。

常见错误

三组直接做三次 t 检验。三次 α = 0.05 的检验让族错误率升到约 14%；ANOVA + 校正事后比较是标准解法。

2. 双因素与交互：性别会修饰海拔效应吗

双因素模型 aov(y ~ A * B) 同时给出 A、B 主效应与 A:B 交互。解释顺序：先看交互——交互显著时主效应会误导；交互不显著时才轮到主效应。

示例 2：海拔 × 性别的双因素模型

A * B交互优先
library(readr); library(dplyr)
pika <- read_csv(here::here("assets/data/pika_physiology.csv"),
                 show_col_types = FALSE)
pika$altitude_group <- factor(pika$altitude_group,
                              levels = c("low", "mid", "high"))
m2 <- aov(body_mass_g ~ altitude_group * sex, data = pika)
summary(m2)
R console
                   Df Sum Sq Mean Sq F value Pr(>F)  
altitude_group      2   1816   908.1   3.818 0.0281 *
sex                 1   1119  1118.9   4.704 0.0345 *
altitude_group:sex  2   1043   521.7   2.193 0.1214  
Residuals          54  12844   237.8                 
---
Signif. codes:  0 '***' 0.001 '**' 0.01 '*' 0.05 '.' 0.1 ' ' 1

逐行解释

  • 第 6 行：* 展开主效应 + 交互；等价于 altitude_group + sex + altitude_group:sex。
  • 第 7 行：海拔 p = 0.028、性别 p = 0.035、交互 p = 0.121。
  • 解释：交互不显著 → 没有证据表明性别改变海拔效应；主效应可分别解释（但注意 ch08 分面图里雌性组的模式看起来更强——那是描述性的，不足以宣称交互）。

常见错误

交互显著还去解释主效应：「海拔总体显著」在交互存在时没有单一含义——差异的方向随性别变。先分层（按性别分别比较海拔），再谈主效应。

3. 前提与稳健性：Levene 与 Kruskal

ANOVA 假设残差近似正态、组内方差相近。Levene 检验查方差；Kruskal–Wallis 是不假设正态的稳健性对照。两者都是「辅助证据」，结论不一致时优先报告更稳健的那个。

示例 3：Levene p = 0.786，Kruskal p = 0.030

leveneTest · kruskal稳健性
library(readr); library(dplyr); suppressPackageStartupMessages(library(car))
pika <- read_csv(here::here("assets/data/pika_physiology.csv"),
                 show_col_types = FALSE)
pika$altitude_group <- factor(pika$altitude_group,
                              levels = c("low", "mid", "high"))
c(levene = round(leveneTest(body_mass_g ~ altitude_group, data = pika)$`Pr(>F)`[1], 3),
  kruskal = round(kruskal.test(body_mass_g ~ altitude_group, data = pika)$p.value, 3))
R console
 levene kruskal 
  0.786   0.030

逐行解释

  • levene p = 0.786：三个海拔组的体重方差没有可检测的差异——ANOVA 的方差前提可接受。
  • kruskal p = 0.030：秩检验同样给出「组间有差异」——与 ANOVA 方向一致，结论不依赖正态假设。
  • 注意：性别两组的方差不齐（3.2 倍，ch11）不代表海拔三组也不齐——前提检查要针对具体模型。

常见错误

残差明显偏态/异方差还硬做 ANOVA 并只报 p。要么用 Kruskal 作主分析，要么用稳健方法并说明；不要「先 ANOVA，不显著再换 Kruskal」。

4. 事后比较：Tukey 校正后的三对 p

总体显著只说明「至少一对不同」。事后比较要控制族错误率：Tukey HSD 同时比较所有对并校正 p。本章结果：三对校正后都 ≥ 0.05——总体显著、两两都不显著，这是最常见的「差异弥散在组间」的情形。

示例 4：TukeyHSD 的三对 p adj

TukeyHSD科研必会
library(readr); library(dplyr)
pika <- read_csv(here::here("assets/data/pika_physiology.csv"),
                 show_col_types = FALSE)
pika$altitude_group <- factor(pika$altitude_group,
                              levels = c("low", "mid", "high"))
m1 <- aov(body_mass_g ~ altitude_group, data = pika)
round(TukeyHSD(m1)$altitude_group[, "p adj"], 3)
R console
 mid-low high-low high-mid 
   0.977    0.054    0.086

逐行解释

  • 第 6 行：TukeyHSD 对 m1 的全部三对做校正比较。
  • 输出：mid-low 0.977、high-low 0.054、high-mid 0.086——最接近显著的是高 vs 低（0.054），但未过 0.05。
  • 报告：「ANOVA 显示组间差异（F(2,57)=3.45, p=0.039），但 Tukey 校正后没有任何一对达到 0.05（最小 p=0.054）」——诚实且信息完整。

常见错误

只报总体 p、不做校正就宣称「高海拔显著低于低海拔」——那是未校正的 0.054 当 0.05 用。事后比较必须用校正后的 p。

5. 端到端：stats_anova.csv 与字母图

结果表记录两个模型的方差分析表（term、df、SS、MS、F、p）；图用均值±SE + 字母表达事后结论。两者合起来就是 Results 段的全部素材。

示例 5：方差分析表 + 字母图落盘

端到端科研必会
library(readr); library(dplyr); library(ggplot2)
suppressPackageStartupMessages({library(emmeans); library(multcomp)})
pika <- read_csv(here::here("assets/data/pika_physiology.csv"),
                 show_col_types = FALSE)
pika$altitude_group <- factor(pika$altitude_group,
                              levels = c("low", "mid", "high"))
m1 <- aov(body_mass_g ~ altitude_group, data = pika)
m2 <- aov(body_mass_g ~ altitude_group * sex, data = pika)
tab <- as.data.frame(summary(m2)[[1]])
stats_anova <- tibble(
  term = rownames(tab),
  df = tab$Df,
  sum_sq = round(tab$`Sum Sq`, 1),
  mean_sq = round(tab$`Mean Sq`, 1),
  f_value = round(tab$`F value`, 2),
  p_value = round(tab$`Pr(>F)`, 4))
dir.create(here::here("data"), showWarnings = FALSE)
write_csv(stats_anova, here::here("data/stats_anova.csv"))
cl <- suppressMessages(cld(emmeans(m1, ~ altitude_group),
                           Letters = letters, adjust = "tukey"))
letters_df <- as.data.frame(cl)[, c("altitude_group", "emmean", "SE", ".group")]
letters_df$.group <- trimws(letters_df$.group)
letters_df
p <- ggplot(letters_df, aes(altitude_group, emmean)) +
  geom_pointrange(aes(ymin = emmean - SE, ymax = emmean + SE)) +
  geom_text(aes(label = .group), vjust = -1.6, size = 3) +
  labs(x = "Altitude group", y = "Body mass (g), mean ± SE") +
  theme_classic(base_size = 9)
dir.create(here::here("figures"), showWarnings = FALSE)
ggsave(here::here("figures/fig_anova_letters.svg"), p,
       width = 89, height = 55, units = "mm")

常见错误

手画字母：凭印象给高海拔标 b。字母必须来自校正后的事后比较（cld 或等价算法），否则图与检验表互相矛盾。

检查点

  • Results 写清「总体显著、事后无显著对」。
  • 交互不显著时，明确写「no evidence of interaction」。
  • 字母与 Tukey p 一致（本例全 a）。

常见错误

Error in `contrasts<-`(`*tmp*`, value = contr.funs[1 + isOF[nn]]) : contrasts can be applied only to factors with 2 or more levels

病因：分组列只有 1 个水平（filter 掉剩一组），或该列是字符未转因子。

修复：检查 table(group)；确保 ≥2 组且为因子。

预防：建模前 count() 分组变量。

Error in TukeyHSD.aov(m1) : no factors in the fitted model

病因：模型里没有因子（比如把分组当数值列放进公式）。

修复：factor() 转换分组变量，再拟合 aov。

预防：公式里的分类变量先因子化（第 3 章的习惯）。

Error in kruskal.test.default(x, g) : all observations are in the same group

病因：分组列只有一个水平（常见于错误 filter）。

修复：核对分组条件；用 table() 确认每组 n。

预防：检验前打印分组计数。

更多同类报错见 R 代码急救室。

交互优先于主效应；事后比较必须校正；字母标记要能自解释。本章的诚实结论：ANOVA 显示组间差异（p = 0.039），但 Tukey 校正后没有任何一对显著（最小 p = 0.054）；交互也无证据（p = 0.121）。这样的结果照样能写——写得清楚比写得漂亮重要。

模型、事后比较、字母图全部由 12_anova.R 生成；报告里的每个 p 都能在 stats_anova.csv 与图 12.1 找到。

Body mass was analysed with one-way and two-way ANOVA (altitude group × sex). Levene's test indicated homogeneous variances across altitude groups (p = 0.79), and a Kruskal–Wallis test gave concordant results (p = 0.03). Tukey-adjusted pairwise comparisons showed no significant pair (smallest adjusted p = 0.054), and the interaction term was not significant (p = 0.12).

中文：体重采用单因素与双因素方差分析（海拔组 × 性别）。Levene 检验显示海拔组间方差齐（p = 0.79），Kruskal–Wallis 结果同向（p = 0.03）；Tukey 校正的两两比较无显著对（最小校正 p = 0.054），交互项不显著（p = 0.12）。

小结

多组用 ANOVA 而不是多次 t；双因素先看交互（本章 p = 0.121 无证据）；总显著 ≠ 两两显著（Tukey 最小 p = 0.054）；字母来自校正后比较，图与表必须一致。稳健性用 Levene + Kruskal 补充。
