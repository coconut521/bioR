回归与线性模型：从趋势到预测

海拔每升 1 米，血红蛋白高 0.016 g/L——这个斜率有 CI，模型有残差，解释有边界。

本章科研问题：血红蛋白随海拔的斜率是多少？性别与体型的效应如何进入模型？

120–150 MIN前置 ch12数据 pika_physiology · pika_survival交付 stats_regression.csv · fig_regression.svg

学习目标

  • 用 lm() 拟合多变量线性模型并读系数表。
  • 用 tidy(conf.int = TRUE) 报告斜率与 95% CI。
  • 用 glance() 读 R²、残差标准误与 AIC，并知道 R² 不是全部。
  • 用 augment() 检查残差正态性、杠杆与异常点。
  • 解释 log-log 模型的斜率（异速指数）。
  • 知道相关不等于因果、外推的边界。

前置：第 12 章；数据：pika_physiology.csv、pika_survival.csv；交付：stats_regression.csv、fig_regression.svg。

ANOVA 把海拔当分类变量——它回答「三组有没有差异」。回归把海拔当连续变量——它回答「每升高一米，血红蛋白变化多少」。选择哪一种由问题决定：要量化趋势与预测，用回归；只比较组别，用 ANOVA。这一章同时练习模型的诊断：斜率再漂亮，残差不对劲也不能信。

1. 线性模型：斜率与 95% CI

lm(y ~ x1 + x2) 拟合线性模型：每个系数是「其他变量不变时，x 增加 1 个单位，y 的平均变化」——这就是「调整后」的含义。系数必须带 CI：斜率的方向与大小都不确定。

示例 1：血红蛋白 ~ 海拔 + 性别

lm · tidy科研必会
library(readr); library(dplyr); library(broom)
pika <- read_csv(here::here("assets/data/pika_physiology.csv"),
                 show_col_types = FALSE)
m1 <- lm(hemoglobin_g_l ~ altitude_m + sex, data = pika)
tidy(m1, conf.int = TRUE) |>
  select(term, estimate, conf.low, conf.high, p.value)
R console
# A tibble: 3 × 5
  term        estimate conf.low conf.high  p.value
  <chr>          <dbl>    <dbl>     <dbl>    <dbl>
1 (Intercept)  95.4     79.7     111.     3.06e-17
2 altitude_m    0.0163   0.0125    0.0200 6.17e-12
3 sexM          4.58    -0.865    10.0    9.75e- 2

逐行解释

  • 第 4 行：两个预测变量；lm 自动剔除含 NA 的行（2 个溶血 NA），有效 n = 58。
  • 海拔斜率：0.0163 g/L 每米（95% CI 0.0125–0.0200）——每 1000 米约 +16 g/L。
  • 性别（M vs F）：+4.58 g/L，CI 跨 0（−0.87 至 10.0），p = 0.098——调整海拔后性别效应不确定。
  • 截距：95.4 g/L 是海拔 0 m、雌性的模型预测——生理上无意义，仅作数学锚点。

常见错误

把斜率 0.0163 写成「海拔导致血红蛋白升高」——这是观察性数据的关联；因果需要设计（处理、随机化、时间顺序），第 16 章再展开。

2. 模型质量：R² 与残差标准误

glance() 给模型级指标：R²（解释的方差比例）、调整 R²、残差标准误（sigma，与原变量同单位）、AIC。R² 高不等于模型对——它只说明「在这批数据里拟合得好」，不说明因果、不外推、不代表预测力。

示例 2：R² = 0.593，sigma = 10.3 g/L

glance模型概览
library(readr); library(dplyr); library(broom)
pika <- read_csv(here::here("assets/data/pika_physiology.csv"),
                 show_col_types = FALSE)
m1 <- lm(hemoglobin_g_l ~ altitude_m + sex, data = pika)
glance(m1) |> select(r.squared, adj.r.squared, sigma, AIC)
R console
# A tibble: 1 × 4
  r.squared adj.r.squared sigma   AIC
      <dbl>         <dbl> <dbl> <dbl>
1     0.593         0.578  10.3  441.

逐行解释

  • R² = 0.593：海拔 + 性别解释了血红蛋白约 59% 的方差。
  • 调整 R² = 0.578：扣除变量个数后的版本，用于比较不同变量数的模型。
  • sigma = 10.3 g/L：残差的标准差——预测值与实测值的典型偏差约 10 g/L，这是「预测有多准」的直接度量。
  • AIC = 441：模型比较用（同一数据集、同一响应变量时越小越好）；不能跨数据集比。

常见错误

「R² 高所以模型好」：R² 随变量增多只升不降；n 小变量多时 R² 可以虚高。看调整 R²、sigma 与残差诊断，再做决定。

3. 诊断：残差、杠杆与外推

augment() 给出每个观测的拟合值、残差、标准化残差与杠杆值（hat）。诊断三问：残差近似正态吗？有没有 |标准化残差| > 2 的点？杠杆大的点是否在自变量极值处？

示例 3：残差 Shapiro、最大杠杆与异常点

augment模型诊断
library(readr); library(dplyr); library(broom)
pika <- read_csv(here::here("assets/data/pika_physiology.csv"),
                 show_col_types = FALSE)
m1 <- lm(hemoglobin_g_l ~ altitude_m + sex, data = pika)
aug <- augment(m1)
c(shapiro_resid = round(shapiro.test(aug$.resid)$p.value, 3),
  max_hat = round(max(aug$.hat), 3),
  big_resid = sum(abs(aug$.std.resid) > 2))
R console
shapiro_resid       max_hat     big_resid 
        0.073         0.063         3.000

逐行解释

  • shapiro_resid = 0.073：残差未拒绝正态——线性模型的分布前提可接受。
  • max_hat = 0.063：最大杠杆 6.3%（60 行模型里远低于 2p/n ≈ 10%）——没有单个点主导拟合。
  • big_resid = 3：3 个观测的标准化残差超过 2 个 SD——不是错误，但要在结果里检查它们是否是同一批/同一海拔。

常见错误

只看 summary 的 p 值不看残差图。异方差（残差随拟合值扩散）会让标准误偏小、p 偏小——这时要用稳健标准误或变换响应变量。

4. 尺度：log-log 异速关系

体型与体长的关系常用幂律 mass ∝ length^b：取 log 后变线性，斜率就是指数 b。注意解释：斜率 1 表示等比例，斜率 3 才是「三维等速生长」的经典预期——数据里的 1.04 说明这批模拟数据没有按立方关系生成。

示例 4：log(体重) ~ log(体长) 的斜率

log-log异速生长
library(readr); library(dplyr); library(broom)
pika <- read_csv(here::here("assets/data/pika_physiology.csv"),
                 show_col_types = FALSE)
m2 <- lm(log(body_mass_g) ~ log(body_length_mm), data = pika)
tidy(m2, conf.int = TRUE) |> select(term, estimate, conf.low, conf.high)
R console
# A tibble: 2 × 4
  term                estimate conf.low conf.high
  <chr>                  <dbl>    <dbl>     <dbl>
1 (Intercept)           -0.322   -3.11       2.46
2 log(body_length_mm)    1.04     0.514      1.57

逐行解释

  • 斜率 1.04（95% CI 0.514–1.57）：体长每增加 1%，体重平均增加约 1%——近似等比例。
  • CI 很宽：n = 60 且体长范围有限；要谈「是否等于 3」显然可以拒绝（CI 不含 3），但「是否等于 1」也不能排除。
  • 解释：log-log 斜率是弹性（百分比对百分比），不是「每毫米多少克」。

常见错误

把 log-log 斜率解释成线性斜率。log 尺度上的 1.04 意味着乘性关系；写报告时要说明「log-log 模型，斜率为异速指数」。

5. 端到端：stats_regression.csv、回归图与逻辑回归

结果表把三个模型的系数并排：连续响应（血红蛋白）、log-log 异速、以及二分类响应的逻辑回归（OR）。注意 glm 的 estimate 是对数几率，exponentiate = TRUE 后才是 OR。

示例 5：三个模型的结果表 + 回归图

端到端科研必会
library(readr); library(dplyr); library(broom); library(ggplot2)
pika <- read_csv(here::here("assets/data/pika_physiology.csv"),
                 show_col_types = FALSE)
surv <- read_csv(here::here("assets/data/pika_survival.csv"),
                 show_col_types = FALSE)
m1 <- lm(hemoglobin_g_l ~ altitude_m + sex, data = pika)
m2 <- lm(log(body_mass_g) ~ log(body_length_mm), data = pika)
g1 <- glm(status ~ treatment, data = surv, family = binomial)
dir.create(here::here("data"), showWarnings = FALSE)
res <- bind_rows(
  tidy(m1, conf.int = TRUE) |>
    transmute(model = "lm: hb ~ altitude + sex", term,
              estimate = round(estimate, 4),
              conf_low = round(conf.low, 4), conf_high = round(conf.high, 4)),
  tidy(m2, conf.int = TRUE) |>
    transmute(model = "lm: log mass ~ log length", term,
              estimate = round(estimate, 3),
              conf_low = round(conf.low, 3), conf_high = round(conf.high, 3)),
  tidy(g1, exponentiate = TRUE, conf.int = TRUE) |>
    transmute(model = "glm: survival ~ treatment (OR)", term,
              estimate = round(estimate, 2),
              conf_low = round(conf.low, 2), conf_high = round(conf.high, 2)))

  labs(x = "Altitude (m)", y = "Haemoglobin (g/L)") +
  theme_classic(base_size = 9)

检查点

  • 斜率写成「每米」还是「每千米」？单位一致。
  • 图注写明「置信带不是预测带」。
  • 因果措辞：用「associated with」，不用「caused by」。

常见错误

Error in lm.fit(x, y, offset = offset, singular.ok = singular.ok, ...) : 0 (non-NA) cases

病因：响应变量或预测变量全是 NA（常见于 join 失败后整列缺失）。

修复：检查 sum(is.na()) 与 join QC；修复数据再建模。

预防：建模前 count() 有效行数。

Error in model.frame.default(formula = y ~ x, data = d) : variable lengths differ (found for 'sex')

病因：公式里用了外部向量（长度与 data 不一致），或 data 参数里没有该列。

修复：所有变量都放在同一个 data 里；核对列名。

预防：公式只用 data 的列，不用全局向量。

Error in eval(family$initialize) : y values must be 0 <= y <= 1

病因：逻辑回归的响应不是 0/1（比如 status 记成了 1/2）。

修复：mutate(status = status - 1) 或重新编码为 0/1 因子。

预防：glm 前 table(y) 确认取值。

更多同类报错见 R 代码急救室。

模型是工具，不是真理。R² = 0.59 说明这批数据里的关联强度；它不证明因果、不支持外推、也不保证预测。诊断（残差、杠杆、异常点）与设计（观察 vs 实验）共同决定解释的边界。

模型公式、诊断与图表全部在 13_regression.R；结果表里的每个系数都能由 tidy() 复现，图由同一脚本渲染。

Haemoglobin was modelled with ordinary least squares as a function of sampling altitude and sex; the altitude coefficient was 0.0163 g/L per metre (95% CI 0.0125–0.0200; R² = 0.59, residual SE = 10.3 g/L). Residuals did not depart from normality (Shapiro–Wilk p = 0.07), and no observation exceeded a hat value of 0.07. A log–log model described body mass as a power function of body length, and a binomial GLM estimated the odds ratio for mortality under hypoxia.

中文：血红蛋白以采样海拔与性别为预测变量做普通最小二乘回归；海拔系数 0.0163 g/L 每米（95% CI 0.0125–0.0200；R² = 0.59，残差 SE = 10.3 g/L）。残差未偏离正态（Shapiro–Wilk p = 0.07），无观测杠杆值超过 0.07。以 log–log 模型描述体重与体长的幂律关系，并以二项 GLM 估计低氧下死亡的优势比。

小结

lm 的系数是「调整后」的边际效应，必须带 CI；R² 与 sigma 一起看；augment 做残差/杠杆诊断；log-log 斜率是异速指数；glm 的 OR 要 exponentiate。相关不等于因果，外推需要数据支撑。
