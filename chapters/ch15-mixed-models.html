混合效应与重复测量：别把伪重复当独立样本

同一只鼠兔测三次，得到的不是三个独立个体。把 36 行当 36 个 n，误差被低估、p 值被压低——这是生物数据最常见的统计事故。

本章科研问题：同一只鼠兔测了 3 次，n 到底是 36 还是 12？

120–150 MIN前置 ch11 · ch13数据 pika_repeated.csv交付 stats_mixed.csv

学习目标

  • 识别嵌套结构：测量嵌套于个体、个体嵌套于批次。
  • 说清 lm() 与 lmer() 在重复测量数据上的差别。
  • 写随机截距模型，读 VarCorr() 与 ICC。
  • 用 emmeans() 做校正后的组间比较。
  • 知道随机效应组数太少、singular fit 与 p 值自由度该怎么处理。

前置：第 11、13 章；数据：pika_repeated.csv（12 只 × 3 次）；交付：stats_mixed.csv。

低氧课题组在同一批鼠兔上测了三次体重与血红蛋白（T0/T14/T28）。若把 36 行当 36 个独立个体，处理组的 SE 会被低估、自由度虚增；正确做法是把个体放进随机截距，让模型知道「这三行来自同一只鼠兔」。

1. 重复测量：一行不是一独立个体

先看轨迹：12 只鼠兔，每只三条线。个体之间的高低差很大，个体内部随时间的变化很小——这正是随机截距要吸收的方差。

2. 同一个效应，两种标准误

先用普通 lm() 把 36 行当独立样本，再用 lmer() 加个体随机截距。固定效应估计值不变，但 SE、df 与 p 会变——因为模型终于承认了重复测量。

示例 1：36 行 vs 12 只——lm 与 lmer 的差别

lmerTest统计单位
suppressPackageStartupMessages({
  library(readr); library(dplyr); library(lme4); library(lmerTest)
})
rep <- read_csv(here::here("assets/data/pika_repeated.csv"), show_col_types = FALSE) |>
  mutate(id = factor(id), treatment = factor(treatment), timepoint = factor(timepoint))
naive <- lm(body_mass_g ~ treatment, data = rep)
mixed <- lmer(body_mass_g ~ treatment + (1 | id), data = rep)
nm <- summary(naive)$coefficients["treatmenthypoxia", ]
mm <- summary(mixed)$coefficients["treatmenthypoxia", ]
data.frame(
  model = c("lm: 36 rows", "lmer: 12 ids"),
  estimate = round(unname(c(nm["Estimate"], mm["Estimate"])), 2),
  SE = round(unname(c(nm["Std. Error"], mm["Std. Error"])), 2),
  df = round(c(naive$df.residual, unname(mm["df"])), 1),
  p = signif(unname(c(nm["Pr(>|t|)"], mm["Pr(>|t|)"])), 2)
)
R console
         model estimate   SE df    p
1  lm: 36 rows    -3.46 5.18 34 0.51
2 lmer: 12 ids    -3.46 8.53 10 0.69

逐行解释

  • 估计值相同：处理组平均低约 3.46 g——混合模型没有改效应，只改了误差结构。
  • SE 从 5.18 涨到 8.53：承认个体差异后，组均值差的不确定性变大。
  • df 从 34 降到 10：独立个体只有 12 只，两组的组间比较自由度约 10。
  • p 从 0.51 到 0.69：两种模型都不显著；但错误的模型会让你误以为证据更强。

常见错误

只报 lm() 的 p 与 df，不说明重复测量；或把 lmer() 的 p 当「更保守」而随意挑选。模型必须由设计决定，不能由结果决定。

3. 方差分解：ICC 告诉你个体有多重要

空模型把体重方差分成两块：个体之间（随机截距）与个体内部（残差）。ICC 是前者占总额的比例——越高，越不能忽略重复测量。

示例 2：VarCorr 与 ICC

performance::icc方差分配
suppressPackageStartupMessages({
  library(readr); library(dplyr); library(lme4); library(performance)
})
rep <- read_csv(here::here("assets/data/pika_repeated.csv"), show_col_types = FALSE) |>
  mutate(id = factor(id), treatment = factor(treatment), timepoint = factor(timepoint))
m0 <- lmer(body_mass_g ~ 1 + (1 | id), data = rep)
vc <- as.data.frame(VarCorr(m0))
icc <- performance::icc(m0)
data.frame(
  component = c("id (between)", "residual (within)", "ICC"),
  variance = round(c(vc$vcov[1], vc$vcov[2], icc$ICC_adjusted), 3)
)
R console
          component variance
1      id (between)  178.409
2 residual (within)   69.700
3               ICC    0.719

逐行解释

  • 个体方差 178.4：不同鼠兔的基线体重差异很大。
  • 残差方差 69.7：同一只鼠兔三次测量之间的波动。
  • ICC = 0.719：约 72% 的体重方差来自个体之间；忽略个体 = 丢掉大部分结构。

常见错误

只报 ICC 不解释：ICC 高说明个体差异大，重复测量必须建模；ICC 接近 0 也不代表可以随意把行当独立——还要看设计是否有嵌套。

4. 固定效应与事后比较

加入时间点后，处理效应是「调整时间点后的组间差」。emmeans() 给出校正后的边际均值与对比；pairs() 的 p 已经是同一模型下的比较。

示例 3：处理 + 时间点的固定效应

emmeans校正比较
suppressPackageStartupMessages({
  library(readr); library(dplyr); library(lme4); library(lmerTest); library(emmeans)
})
rep <- read_csv(here::here("assets/data/pika_repeated.csv"), show_col_types = FALSE) |>
  mutate(id = factor(id), treatment = factor(treatment), timepoint = factor(timepoint))
m <- lmer(body_mass_g ~ treatment + timepoint + (1 | id), data = rep)
coefs <- summary(m)$coefficients
coefs <- coefs[rownames(coefs) != "(Intercept)", , drop = FALSE]
data.frame(
  term = rownames(coefs),
  estimate = round(coefs[, "Estimate"], 3),
  SE = round(coefs[, "Std. Error"], 3),
  p = round(coefs[, "Pr(>|t|)"], 3)
)
emm <- emmeans(m, ~ treatment)
pr <- as.data.frame(pairs(emm))
data.frame(contrast = as.character(pr$contrast),
           estimate = round(pr$estimate, 2),
           SE = round(pr$SE, 2), p = round(pr$p.value, 3))
R console
                             term estimate    SE     p
treatmenthypoxia treatmenthypoxia   -3.461 8.529 0.693
timepointT14         timepointT14    4.025 3.405 0.250
timepointT28         timepointT28   -0.358 3.405 0.917
           contrast estimate   SE     p
1 control - hypoxia     3.46 8.53 0.693

逐行解释

  • treatmenthypoxia = −3.46：调整时间点后，低氧组平均低 3.46 g（SE 8.53，p = 0.693）。
  • T14 = +4.03 / T28 = −0.36：相对 T0 的变化很小，p 均不显著。
  • emmeans 对比：control − hypoxia = 3.46 g，与固定效应一致；SE 相同，说明这是同一模型的边际比较。
  • 不要把 pairs() 的 p 再乘次数——emmeans 已在该模型框架内比较。

常见错误

对重复测量数据跑三次 t.test()：每个时间点单独比较会丢掉个体随机效应，也会重复使用同一批个体。用同一个混合模型 + emmeans。

5. 组数太少与模型比较

随机效应不是越多越好：批次只有 2 个水平时，方差估计很不稳定，AIC 反而变差。随机效应的组数太少时，lmer() 常给出 singular fit（方差估成 0）——这不是「模型没问题」，而是数据不支持这个随机效应。

示例 4：加 batch 随机效应，值不值？

anova · AICsingular fit
suppressPackageStartupMessages({
  library(readr); library(dplyr); library(lme4)
})
rep <- read_csv(here::here("assets/data/pika_repeated.csv"), show_col_types = FALSE) |>
  mutate(id = factor(id), treatment = factor(treatment), batch = factor(batch))
m1 <- lmer(body_mass_g ~ treatment + (1 | id), data = rep, REML = FALSE)
m2 <- suppressWarnings(lmer(body_mass_g ~ treatment + (1 | id) + (1 | batch),
                            data = rep, REML = FALSE))
cmp <- anova(m1, m2)
data.frame(
  model = c("id only", "id + batch"),
  AIC = round(cmp$AIC, 1),
  LRT = c(NA, round(cmp$Chisq[2], 2)),
  p = c(NA, round(cmp$`Pr(>Chisq)`[2], 3)),
  singular = c(isSingular(m1), isSingular(m2))
)
vc <- as.data.frame(VarCorr(m2))
vc[, c("grp", "vcov")]
R console
       model   AIC  LRT    p singular
1    id only 287.6   NA   NA    FALSE
2 id + batch 289.6 0.07 0.79    FALSE
       grp       vcov
1       id 149.222234
2    batch   9.388036
3 Residual  69.699999

逐行解释

  • AIC 287.6 → 289.6：加 batch 后模型更差；LRT p = 0.79，没有证据支持批次方差。
  • batch 方差 9.4：很小，且只有 2 个批次，估计不稳定。
  • isSingular 都 FALSE：本例还没到奇异；但若方差被估成 0，isSingular() 会返回 TRUE。
  • 处理方式：singular fit 时删掉该随机效应或改用固定效应，并在报告中说明——不要静默忽略 warning。

常见错误

lmer() 打印 boundary (singular) fit 后继续照常解释。singular fit 说明随机效应方差在边界 0，模型没有估计到它；先简化随机结构，再检查固定效应。

6. 交付：stats_mixed.csv

把最终模型的固定效应表写成交付物：term、estimate、SE、95% CI、df、t、p。ICC 一起报告；若处理效应不显著，就如实写「无证据」，而不是换模型直到显著。

示例 5：写出 stats_mixed.csv

write_csv交付物
suppressPackageStartupMessages({
  library(readr); library(dplyr); library(lme4); library(lmerTest); library(performance)
})
rep <- read_csv(here::here("assets/data/pika_repeated.csv"), show_col_types = FALSE) |>
  mutate(id = factor(id), treatment = factor(treatment), timepoint = factor(timepoint))
m <- lmer(hemoglobin_g_l ~ treatment + timepoint + (1 | id), data = rep)
coefs <- summary(m)$coefficients
est <- coefs[, "Estimate"]
se <- coefs[, "Std. Error"]
res <- data.frame(
  term = rownames(coefs),
  estimate = round(est, 3),
  SE = round(se, 3),
  conf_low = round(est - 1.96 * se, 3),
  conf_high = round(est + 1.96 * se, 3),
  df = round(coefs[, "df"], 2),
  t = round(coefs[, "t value"], 2),
  p = signif(coefs[, "Pr(>|t|)"], 3)
)
dir.create(here::here("data"), showWarnings = FALSE)
write_csv(res, here::here("data/stats_mixed.csv"))
data.frame(
  file = "data/stats_mixed.csv",
  rows = nrow(res),
  ICC = round(performance::icc(m)$ICC_adjusted, 3),
  max_p = signif(max(res$p), 2)
)
R console
                  file rows   ICC max_p
1 data/stats_mixed.csv    4 0.684  0.35

逐行解释

  • 4 行固定效应：截距、treatment、T14、T28；每行都有 SE、95% CI、df、t、p。
  • ICC = 0.684：血红蛋白的个体差异仍占大部分方差。
  • max_p = 0.35：在本数据中没有显著的处理或时间效应；报告估计与 CI，不宣称「有效」。
  • 文件位置：data/stats_mixed.csv，与其它章节交付物同一目录。

常见错误

把 summary(m) 的整页文本粘进报告，或把 p 值四舍五入成 0.000。交付表只保留需要的列，p 用科学计数或「<0.001」表述。

科研任务：把重复测量模型写进分析脚本

在本章脚本基础上产出 R/15_mixed.R 与交付物。

  1. 识别单位：确认数据是 12 只 × 3 次；写出统计单位与 n。
  2. 方差分解：空模型 + ICC；解释个体差异是否不可忽略。
  3. 固定效应：treatment + timepoint + (1|id)；用 emmeans 报告校正比较。
  4. 交付：data/stats_mixed.csv；报告中写 ICC、效应量、CI 与「无证据」的结论。

检查点

  • n 报告为 12 只（或每组 6 只），不是 36 行。
  • 模型公式含 (1 | id)；ICC 写进结果。
  • 不显著就说「无证据」，不删个体、不换模型凑 p。

常见错误

Error: grouping factors must have > 1 sampled level

病因：随机效应的分组变量只有一个水平（例如所有行都标 one = "A"）。

修复：检查分组变量；一个水平无法估计方差，删掉该随机效应或改固定效应。

预防：建模前 table(group)，确认每个随机效应 ≥ 2 个水平。

Error: No random effects terms specified in formula

病因：调用 lmer() 却忘了写 (1 | id) 之类的随机项。

修复：加随机截距，或改用 lm()（如果设计确实独立）。

预防：先写设计（个体/批次），再写公式；随机项与设计一一对应。

Error: contrasts can be applied only to factors with 2 or more levels

病因：固定效应因子只剩一个水平（过滤/子集后常见）。

修复：droplevels()；确认子集后仍有两个以上组。

预防：建模前 table(d$group) 检查每组样本。

更多同类报错见 R 代码急救室。

统计单位由设计决定，不由行数决定。同一只个体测三次，n 仍是个体数；随机截距把「同一个个体的测量」连在一起。判断一个模型是否合理，先问：它承认了数据里的哪几层嵌套？

本章示例全部由 tools/examples/ch15-ex-*.R 在独立 R 进程中运行；输出由 render-examples.R 注入、check-examples.R 逐字校验——包括 ICC 与 p 值。

Repeated measurements on the same individuals were analysed with linear mixed-effects models including a random intercept for individual (lmerTest; REML), because observations within an individual are not independent; the intraclass correlation coefficient was 0.72 for body mass, and treatment effects were estimated with Satterthwaite degrees of freedom and reported with 95% confidence intervals.

中文：同一个体的重复测量用含个体随机截距的线性混合模型分析（lmerTest；REML），因为个体内观测不独立；体重 ICC 为 0.72；处理效应用 Satterthwaite 自由度估计，并报告 95% 置信区间。

小结

重复测量三件事：统计单位是个体（不是行）、模型加随机截距（(1 | id)）、报告 ICC 与校正后的效应。随机效应组数太少会 singular；p 值要看自由度来源；不显著就写「无证据」。
