生存分析：时间到事件

到第 60 天还活着的个体不是「缺失值」——它们提供了「至少活到 60 天」的信息。删掉它们，等于把最长寿的个体从曲线里抹去。

本章科研问题：低氧是否缩短生存时间？到终点仍存活的个体，信息该怎么用？

90–120 MIN前置 ch13 · ch15数据 pika_survival.csv交付 fig_survival.svg · stats_cox.csv

学习目标

  • 区分事件时间与删失时间，知道删失为什么不是缺失。
  • 读 Kaplan–Meier 曲线与中位生存期（含 95% CI）。
  • 用 log-rank 比较曲线，用 Cox 模型报告风险比 HR。
  • 检查 PH 假设（cox.zph()），知道不满足时该怎么做。
  • 交付带风险表的 KM 图与 Cox 结果表。

前置：第 13、15 章；数据：pika_survival.csv（60 只，60 天随访）；交付：fig_survival.svg、stats_cox.csv。

60 只鼠兔随机分到对照与低氧组，随访 60 天。终点是死亡；到 60 天仍存活、或中途失访的个体记为删失（status = 0）。研究问题是：低氧是否缩短生存时间？HR 有多大？

1. 删失：不是缺失，是「至少活到这里」

先数清楚：每组 30 只，对照 21 个事件 / 9 个删失，低氧 27 个事件 / 3 个删失。删失个体在离开风险集之前一直贡献信息，不能当缺失删除。

示例 1：事件、删失与随访时间

dplyr先数清楚
suppressPackageStartupMessages({
  library(readr); library(dplyr); library(survival)
})
d <- read_csv(here::here("assets/data/pika_survival.csv"), show_col_types = FALSE) |>
  mutate(status = as.integer(status), treatment = factor(treatment))
d |>
  group_by(treatment) |>
  summarise(n = n(), events = sum(status), censored = sum(status == 0),
            median_follow = median(time_days), max_follow = max(time_days)) |>
  ungroup() |>
  as.data.frame()
R console
  treatment  n events censored median_follow max_follow
1   control 30     21        9            45         60
2   hypoxia 30     27        3            31         60

逐行解释

  • events / censored：对照 21/9，低氧 27/3；删失比例不同，不能直接比原始死亡数。
  • median_follow：随访时间的中位数；对照 45 天、低氧 31 天，低氧组更早到达终点。
  • max_follow = 60：所有个体最多随访 60 天；到 60 天仍存活的记录为删失。

常见错误

把 status == 0 的行删掉再算平均生存时间：最长寿的个体被系统性剔除，生存被低估、组间差被夸大。

2. KM 曲线与中位生存

Kaplan–Meier 在每个事件时间点更新生存概率；中位生存是曲线首次降到 0.5 的时间。低氧组中位 31 天，对照组 46 天——但要看 CI，而不是只报一个点。

示例 2：中位生存与 95% CI

survfitKM
suppressPackageStartupMessages({
  library(readr); library(dplyr); library(survival)
})
d <- read_csv(here::here("assets/data/pika_survival.csv"), show_col_types = FALSE) |>
  mutate(status = as.integer(status), treatment = factor(treatment))
fit <- survfit(Surv(time_days, status) ~ treatment, data = d)
tb <- summary(fit)$table
data.frame(
  group = unname(sub("treatment=", "", rownames(tb))),
  n = unname(tb[, "records"]),
  events = unname(tb[, "events"]),
  median_days = unname(round(tb[, "median"], 1)),
  LCL = unname(round(tb[, "0.95LCL"], 1)),
  UCL = unname(round(tb[, "0.95UCL"], 1)),
  row.names = NULL
)
R console
    group  n events median_days LCL UCL
1 control 30     21          46  35  NA
2 hypoxia 30     27          31  22  44

逐行解释

  • control：46 天（35–未达）：CI 上界未达，因为曲线在 60 天前没有降到足够低。
  • hypoxia：31 天（22–44）：中位生存更短，CI 也更窄。
  • 中位生存 ≠ 平均生存：删失会让均值不可估；中位数是 KM 的标准汇总。

常见错误

把「60 天生存率」当「治愈率」，或只报中位数不报 CI；中位生存缺失（曲线未降到 0.5）时应写「未达」，不能写 0。

3. log-rank 与 Cox：曲线差与风险比

log-rank 检验整条曲线是否相同；Cox 模型给出调整协变量后的风险比 HR。HR = 2.13 表示任一时点低氧组的瞬时死亡风险约是对照的 2 倍，不是「死亡率高 113%」的绝对表述。

示例 3：log-rank 与 Cox HR

survdiff · coxph效应量
suppressPackageStartupMessages({
  library(readr); library(dplyr); library(survival)
})
d <- read_csv(here::here("assets/data/pika_survival.csv"), show_col_types = FALSE) |>
  mutate(status = as.integer(status), treatment = factor(treatment))
lr <- survdiff(Surv(time_days, status) ~ treatment, data = d)
cox <- coxph(Surv(time_days, status) ~ treatment, data = d)
s <- summary(cox)
r1 <- data.frame(
  test = "log-rank",
  value = round(lr$chisq, 2), lower = NA, upper = NA,
  p = signif(pchisq(lr$chisq, df = 1, lower.tail = FALSE), 3)
)
r2 <- data.frame(
  test = paste0("Cox HR: ", rownames(s$conf.int)),
  value = round(s$conf.int[, "exp(coef)"], 2),
  lower = round(s$conf.int[, "lower .95"], 2),
  upper = round(s$conf.int[, "upper .95"], 2),
  p = signif(s$coefficients[, "Pr(>|z|)"], 3)
)
rbind(r1, r2)
R console
                      test value lower upper       p
1                 log-rank  6.67    NA    NA 0.00983
2 Cox HR: treatmenthypoxia  2.13  1.19  3.84 0.01140

逐行解释

  • log-rank χ² = 6.67，p = 0.0098：整条曲线有差异；它不给出效应量。
  • HR = 2.13（1.19–3.84），p = 0.0114：低氧的瞬时死亡风险约为对照的 2 倍。
  • CI 很宽：60 只、30 个事件，HR 的方向明确但精度有限；报告 CI，不只报 p。

常见错误

用 t 检验比较生存时间；或把 HR 当绝对风险差。HR 是相对风险，必须连同基线风险/生存曲线一起解释。

4. PH 假设：HR 是否随时间恒定

Cox 模型假设风险比不随时间变化。用 cox.zph() 检查：p 大表示没有证据反对 PH；p 小则要分层、加时变项或改用其他模型。

示例 4：cox.zph 检查 PH

cox.zph前提检查
suppressPackageStartupMessages({
  library(readr); library(dplyr); library(survival)
})
d <- read_csv(here::here("assets/data/pika_survival.csv"), show_col_types = FALSE) |>
  mutate(status = as.integer(status), treatment = factor(treatment))
cox <- coxph(Surv(time_days, status) ~ treatment, data = d)
z <- cox.zph(cox)
data.frame(
  term = rownames(z$table),
  chisq = round(z$table[, "chisq"], 2),
  df = z$table[, "df"],
  p = round(z$table[, "p"], 3)
)
R console
               term chisq df     p
treatment treatment  0.02  1 0.881
GLOBAL       GLOBAL  0.02  1 0.881

逐行解释

  • treatment χ² = 0.02，p = 0.881：没有证据表明 HR 随时间变化。
  • GLOBAL 同样 p = 0.881：整体 PH 假设通过。
  • p 大不是「证明 PH 成立」：只是没有足够证据反对；仍要看 KM 曲线是否交叉。

常见错误

不看 PH 就直接解释 HR；或 PH 不满足时硬报一个「平均 HR」。曲线交叉时 HR 可能没有单一含义。

5. 交付：KM 图（含风险表）与 Cox 表

最终交付两张东西：一张能独立读懂的 KM 图（含删失标记与风险人数），一张 Cox 结果表（HR、95% CI、p）。图由代码生成，数字与表来自同一次运行。

示例 5：fig_survival.svg + stats_cox.csv

patchwork交付物
suppressPackageStartupMessages({
  library(readr); library(dplyr); library(survival); library(broom)
  library(ggplot2); library(patchwork)

d <- read_csv(here::here("assets/data/pika_survival.csv"), show_col_types = FALSE) |>

cox <- coxph(Surv(time_days, status) ~ treatment, data = d)
s <- summary(cox)

  lower = round(s$conf.int[, "lower .95"], 3),
  upper = round(s$conf.int[, "upper .95"], 3),

)
write_csv(res, here::here("data/stats_cox.csv"))
km <- broom::tidy(fit)
km$strata <- factor(km$strata, levels = c("treatment=control", "treatment=hypoxia"))

                      breaks = c("treatment=control", "treatment=hypoxia"),
                      labels = c("control", "hypoxia")) +
  coord_cartesian(ylim = c(0, 1)) +
  labs(x = "Days", y = "Survival probability", colour = "Treatment") +
  theme_classic(base_size = 8)
tt <- c(0, 20, 40, 60)
sm <- summary(fit, times = tt)
risk <- data.frame(time = sm$time, strata = sm$strata, n = sm$n.risk)
risk$strata <- factor(risk$strata, levels = c("treatment=control", "treatment=hypoxia"))
p_risk <- ggplot(risk, aes(time, strata, label = n)) +
  geom_text(size = 2.6, colour = "#333333") +

常见错误

只交一张没有风险表的 KM 图，或图里的数字与稿件的 n/事件数对不上。图和表必须来自同一次运行、同一个数据集。

科研任务：低氧生存分析

把本章操作串成 R/16_survival.R，产出交付物。

  1. 核对删失：写出每组 n、事件、删失；确认最大随访 60 天。
  2. KM：中位生存 + 95% CI；画 KM 并加风险表。
  3. 检验：log-rank + Cox；报告 HR、95% CI、p。
  4. 前提：cox.zph；说明 PH 是否通过；不通过就改模型。
  5. 交付：data/stats_cox.csv 与 figures/fig_survival.svg。

检查点

  • 删失个体全部保留；没有把 status=0 的行删掉。
  • 图注含 n、事件数、中位生存与 log-rank p。
  • HR 与 CI 一起报告；没有把 HR 解释成绝对风险。

常见错误

Error: Response must be a survival object

病因：coxph() / survfit() 的公式只写了 status，没有 Surv(time, status)。

修复：写成 Surv(time_days, status) ~ treatment。

预防：生存模型先建 Surv 对象，再写协变量。

Error: There is only 1 group

病因：subset 后只剩一个处理组，log-rank 没有可比较的第二组。

修复：恢复对照组，或检查 subset 条件。

预防：比较前 table(d$treatment)。

Error: Invalid survival times for this distribution

病因：参数生存模型收到 ≤0 的时间，或时间/状态列错位。

修复：检查 summary(time)；时间必须为正，状态为 0/1。

预防：读入后立即检查 range(time_days) 与 table(status)。

更多同类报错见 R 代码急救室。

删失是信息，不是缺失。删失个体告诉我们「至少活到 t」，KM 与 Cox 都会正确使用这段信息。把删失删掉，相当于只留下死亡者，生存被系统性低估；HR 也会偏向「处理更危险」。

本章 KM 图由 survfit() + broom::tidy() 生成，风险表来自 summary(fit, times=...)；示例 5 的图与表由同一脚本、同一次运行产出。

Survival was analysed with Kaplan–Meier curves and a log-rank test; a Cox proportional-hazards model estimated the hazard ratio for hypoxia versus control (HR 2.13, 95% CI 1.19–3.84, p = 0.011), and the proportional-hazards assumption was checked with scaled Schoenfeld residuals (cox.zph, p = 0.88); censored observations were retained in the risk set.

中文：生存数据用 Kaplan–Meier 曲线与 log-rank 检验分析；Cox 比例风险模型估计低氧相对对照的风险比（HR 2.13，95% CI 1.19–3.84，p = 0.011）；用缩放 Schoenfeld 残差检验 PH 假设（cox.zph，p = 0.88）；删失观测保留在风险集中。

小结

生存分析四件套：删失保留、KM 看曲线、log-rank 看整体差异、Cox 报 HR 与 CI。中位生存要带 CI；PH 假设要检查；HR 是相对风险，不是绝对死亡率。
