转录组差异分析：从 counts 到基因列表

差异分析不是「跑个 DESeq2」。设计公式、低表达过滤、收缩、FDR 与富集背景，每一步都能让基因列表失真。

本章科研问题：padj = 0.01 但 log2FC 只有 0.3，算不算生物学上有意义？

150–180 MIN前置 ch17 · ch13数据 counts 2000×12交付 de_results.csv · fig_volcano.svg · fig_enrichment.svg

学习目标

  • 用 DESeqDataSetFromMatrix() 建立 counts 与样本表的对象。
  • 理解设计公式：为什么本数据不能写 ~ batch + group。
  • 用 lfcShrink() 收缩 log2FC，读 FDR 与效应量。
  • 画火山图，按 padj 与 |log2FC| 双阈值筛选基因。
  • 做富集并正确解释「无显著通路」；知道背景基因集与 ID 版本的重要性。

前置：第 17、13 章；数据：counts、clean metadata、annotation；交付：de_results.csv、fig_volcano.svg、fig_enrichment.svg。

低氧 vs 对照，6 vs 6。设计表里 group 与 batch 完全重合：对照全在 batch1、低氧全在 batch2。因此 ~ batch + group 的模型矩阵不满秩，DESeq2 会直接报错；唯一能拟合的是 ~ group，但结论必须写明「处理/批次混合效应」。

1. 设计先于模型：不满秩的设计

先看交叉表：control 6 个全在 batch1，hypoxia 6 个全在 batch2。完全混杂意味着「处理效应」与「批次效应」在数学上无法分离；这不是代码问题，是设计问题。

示例 1：分组 × 批次交叉表

table混杂检查
suppressPackageStartupMessages({

})
counts <- read_csv(here::here("assets/data/pika_rnaseq_counts.csv"), show_col_types = FALSE) |>
  column_to_rownames("gene_id")
meta <- read_csv(here::here("assets/data/pika_rnaseq_metadata_clean.csv"),
                 show_col_types = FALSE)
ct <- table(group = meta$group, batch = meta$batch)
data.frame(
  group = rownames(ct),
  batch1 = as.integer(ct[, "batch1"]),
  batch2 = as.integer(ct[, "batch2"])
)
c(genes = nrow(counts), samples = ncol(as.matrix(counts[, meta$sample_id])))
R console
    group batch1 batch2
1 control      6      0
2 hypoxia      0      6
  genes samples 
   2000      12

逐行解释

  • control: 6/0、hypoxia: 0/6：两组的批次完全分开。
  • 2000 基因 × 12 样本：列按样本表顺序取，避免错位。
  • 能写什么模型：只能 ~ group；写 ~ batch + group 会因为共线而不满秩。

常见错误

看到 batch 列就无脑加进 design。设计矩阵不是「变量越多越好」；共线的变量会让模型无法估计。

2. DESeq2：过滤、归一化、负二项模型

先过滤低表达基因，再用负二项模型估计处理效应。results() 输出 log2FC、SE、pvalue 与 padj；padj 是 BH 校正后的 FDR，基因列表以它为准。

示例 2：DESeq 与结果计数

DESeq2主分析
suppressPackageStartupMessages({
  library(readr); library(dplyr); library(tibble); library(DESeq2)
})
counts <- read_csv(here::here("assets/data/pika_rnaseq_counts.csv"), show_col_types = FALSE) |>
  column_to_rownames("gene_id")
meta <- read_csv(here::here("assets/data/pika_rnaseq_metadata_clean.csv"),
                 show_col_types = FALSE)
mat <- as.matrix(counts[, meta$sample_id])
dds <- suppressMessages(suppressWarnings(DESeqDataSetFromMatrix(mat, meta, ~ group)))
dds <- dds[rowSums(counts(dds) >= 10) >= 6, ]
dds <- suppressMessages(DESeq(dds))
res <- results(dds, contrast = c("group", "hypoxia", "control"))
data.frame(
  tested = sum(!is.na(res$padj)),
  padj_0.05 = sum(res$padj < 0.05, na.rm = TRUE),
  up = sum(res$padj < 0.05 & res$log2FoldChange > 1, na.rm = TRUE),
  down = sum(res$padj < 0.05 & res$log2FoldChange < -1, na.rm = TRUE)
)
R console
  tested padj_0.05 up down
1   1995        74 65    7

逐行解释

  • 1995 个可检验基因：5 个因全零或低表达被过滤。
  • 74 个 padj < 0.05：统计显著；但还要看效应量与方向。
  • 65 上调 / 7 下调（未收缩 log2FC）：初步列表；收缩后数量会变（见下）。
  • 设计只有 group：不能把 74 个基因全部归因于低氧；批次同样可能造成。

常见错误

用 pvalue 而不是 padj 选基因；或不看 log2FC 方向与大小，只按 p 排序。

3. 收缩与火山图：效应量比 p 更重要

lfcShrink()（apeglm）把噪声大的 log2FC 向 0 收缩，尤其保护低表达基因。火山图同时展示效应量与 FDR；双阈值（padj < 0.05 且 |log2FC| > 1）是常用但需要理由的规则。

示例 3：apeglm 收缩与 fig_volcano.svg

lfcShrink交付物
suppressPackageStartupMessages({
  library(readr); library(dplyr); library(tibble); library(DESeq2)
  library(apeglm); library(ggplot2)
})
counts <- read_csv(here::here("assets/data/pika_rnaseq_counts.csv"), show_col_types = FALSE) |>
  column_to_rownames("gene_id")
meta <- read_csv(here::here("assets/data/pika_rnaseq_metadata_clean.csv"),
                 show_col_types = FALSE)
mat <- as.matrix(counts[, meta$sample_id])
dds <- suppressMessages(suppressWarnings(DESeqDataSetFromMatrix(mat, meta, ~ group)))
dds <- dds[rowSums(counts(dds) >= 10) >= 6, ]
dds <- suppressMessages(DESeq(dds))
res <- suppressMessages(lfcShrink(dds, coef = "group_hypoxia_vs_control", type = "apeglm"))
df <- as.data.frame(res) |>
  rownames_to_column("gene_id")
df$sig <- ifelse(is.na(df$padj) | df$padj >= 0.05 | abs(df$log2FoldChange) <= 1, "ns",
                 ifelse(df$log2FoldChange > 1, "up", "down"))
p <- ggplot(df, aes(log2FoldChange, -log10(padj), colour = sig)) +
  geom_point(size = .7, alpha = .7, na.rm = TRUE) +
  scale_colour_manual(values = c(up = "#D55E00", down = "#0072B2", ns = "#B5A48D")) +
  geom_vline(xintercept = c(-1, 1), linetype = "dashed", linewidth = .3) +
  geom_hline(yintercept = -log10(0.05), linetype = "dashed", linewidth = .3) +
  labs(x = "shrunken log2 fold change", y = "-log10(padj)", colour = "FDR + LFC") +
  theme_classic(base_size = 9)
dir.create(here::here("figures"), showWarnings = FALSE)
ggsave(here::here("figures/fig_volcano.svg"), p, width = 89, height = 70, units = "mm")
data.frame(
  file = "figures/fig_volcano.svg",
  exists = file.exists(here::here("figures/fig_volcano.svg")),
  up = sum(df$sig == "up"), down = sum(df$sig == "down"), ns = sum(df$sig == "ns")
)
R console
                     file exists up down   ns
1 figures/fig_volcano.svg   TRUE 49    5 1942

逐行解释

  • 收缩后 49 上调 / 5 下调：比未收缩的 65/7 少——低表达、噪声大的 LFC 被拉回 0。
  • 阈值双条件：padj < 0.05 且 |log2FC| > 1；单看 p 会把微小变化也算进去。
  • 火山图图注：写 n、阈值、方向计数与混杂限制。

常见错误

用未收缩的 log2FC 画火山图并宣称「大幅上调」；低表达基因的 LFC 噪声极大。收缩后再报告。

4. 富集：先问背景，再问通路

富集把基因列表映射到通路。背景必须是「实际检测到的基因」，ID 版本必须与注释一致。富集结果只是假设：本数据的 72 个差异基因没有一条 KEGG 通路通过 FDR。

示例 4：clusterProfiler enricher

clusterProfiler结果为空
suppressPackageStartupMessages({
  library(readr); library(dplyr); library(tidyr); library(tibble); library(DESeq2)
  library(clusterProfiler)
})
counts <- read_csv(here::here("assets/data/pika_rnaseq_counts.csv"), show_col_types = FALSE) |>
  column_to_rownames("gene_id")
meta <- read_csv(here::here("assets/data/pika_rnaseq_metadata_clean.csv"),
                 show_col_types = FALSE)
ann <- read_csv(here::here("assets/data/pika_annotation.csv"), show_col_types = FALSE)
mat <- as.matrix(counts[, meta$sample_id])
dds <- suppressMessages(suppressWarnings(DESeqDataSetFromMatrix(mat, meta, ~ group)))
dds <- dds[rowSums(counts(dds) >= 10) >= 6, ]
dds <- suppressMessages(DESeq(dds))
res <- results(dds, contrast = c("group", "hypoxia", "control"))
genes <- rownames(res)[!is.na(res$padj) & res$padj < 0.05 & abs(res$log2FoldChange) > 1]
t2g <- ann |>
  select(kegg_pathway, gene_id) |>
  separate_rows(kegg_pathway, sep = ";") |>
  filter(!is.na(kegg_pathway), kegg_pathway != "")
en <- enricher(genes, TERM2GENE = t2g, universe = rownames(dds),
               pvalueCutoff = 1, qvalueCutoff = 1)
out <- as.data.frame(en)
data.frame(
  term = out$ID[1:4],
  ratio = out$GeneRatio[1:4],
  p_adjust = signif(out$p.adjust[1:4], 3)
)
R console
                                  term ratio p_adjust
1    ko00190 oxidative phosphorylation 12/72    0.821
2 ko00010 glycolysis / gluconeogenesis 11/72    0.821
3                    ko04145 phagosome 10/72    0.821
4 ko04610 NF-kappa B signaling pathway  9/72    0.836

逐行解释

  • 72 个差异基因（未收缩阈值）进入富集；背景是 1996 个可检验基因。
  • TERM2GENE 顺序：第一列 term、第二列 gene；反过来会「没有基因能映射」。
  • p.adjust 全在 0.82 以上：没有显著富集；正确结论是「未发现通路证据」。
  • 不要强行解释：把 nominal p 最小的通路写成「富集」是常见的过度解读。

常见错误

背景用全基因组而不是实际检测基因；或基因 ID 与注释版本不匹配，导致一半基因映射失败却不检查。

5. 交付：结果表、火山图与富集图

交付三件：完整 DE 结果表（所有可检验基因）、火山图、富集图。图注与报告必须写清 design、阈值、FDR 方法与混杂限制。

suppressPackageStartupMessages({
  library(readr); library(dplyr); library(tidyr); library(tibble); library(DESeq2)
  library(apeglm); library(clusterProfiler); library(ggplot2)
})
counts <- read_csv(here::here("assets/data/pika_rnaseq_counts.csv"), show_col_types = FALSE) |>

meta <- read_csv(here::here("assets/data/pika_rnaseq_metadata_clean.csv"),
                 show_col_types = FALSE)
ann <- read_csv(here::here("assets/data/pika_annotation.csv"), show_col_types = FALSE)
mat <- as.matrix(counts[, meta$sample_id])
dds <- suppressMessages(suppressWarnings(DESeqDataSetFromMatrix(mat, meta, ~ group)))
dds <- dds[rowSums(counts(dds) >= 10) >= 6, ]
dds <- suppressMessages(DESeq(dds))
res <- suppressMessages(lfcShrink(dds, coef = "group_hypoxia_vs_control", type = "apeglm"))
de <- as.data.frame(res) |>
  rownames_to_column("gene_id") |>
  left_join(select(ann, gene_id, symbol), by = "gene_id") |>

t2g <- ann |>
  select(kegg_pathway, gene_id) |>
  separate_rows(kegg_pathway, sep = ";") |>
  filter(!is.na(kegg_pathway), kegg_pathway != "")
en <- enricher(genes, TERM2GENE = t2g, universe = rownames(dds),
               pvalueCutoff = 1, qvalueCutoff = 1)
enr <- as.data.frame(en) |>
  mutate(ratio = vapply(strsplit(GeneRatio, "/"), function(x) as.numeric(x[1]) / as.numeric(x[2]), 0)) |>

p <- ggplot(enr, aes(ratio, reorder(Description, ratio), size = Count, colour = p.adjust)) +

  scale_colour_viridis_c(option = "C", trans = "reverse", name = "p.adjust") +
  labs(x = "Gene ratio", y = NULL, size = "Genes") +

常见错误

只交「显著基因列表」而不交完整结果表：读者无法检查阈值、FDR 分布与效应量；补充材料也复现不了。

科研任务：低氧 vs 对照的 DE 报告

把本章操作串成 R/18_rnaseq.R，产出三件交付物与一段限制说明。

  1. 设计：交叉表确认 group/batch 完全重合；写「不能分离」。
  2. DE：过滤低表达、~ group、DESeq、apeglm 收缩。
  3. 筛选：padj < 0.05 且 |log2FC| > 1；报告上调/下调数与完整表。
  4. 富集：自定义 TERM2GENE、背景为可检验基因；如实报告无显著通路。
  5. 交付：de_results.csv、fig_volcano.svg、fig_enrichment.svg。

检查点

  • 设计公式与交叉表一致；没有写 ~ batch + group。
  • 用 padj 与 LFC 双阈值；报告收缩方法与版本。
  • 富集结果为空时写「未发现」，不解释 nominal p。

常见错误

Error in checkFullRank(modelMatrix) : the model matrix is not full rank, so the model cannot be fit as specified. One or more variables or interaction terms in the design formula are linear combinations of the others and must be removed.

病因：design 写了 ~ batch + group，而本数据 group 与 batch 完全重合。

修复：删掉无法估计的项（只留 ~ group），并在报告里说明混杂。

预防：建模前 table(group, batch)；完全混杂只能重做设计。

Error: contrasts can be applied only to factors with 2 or more levels

病因：过滤或 subset 后 group 只剩一个水平。

修复：droplevels()；确认两组都有样本。

预防：建模前 table(meta$group)。

Error: 'assets/data/does_not_exist.csv' does not exist in current working directory: 'C:/Users/Choi/Documents/ZCode/bioR'.

病因：相对路径按当前工作目录解析，counts/annotation 文件不在那里。

修复：用 here::here("assets/data/…")；先 file.exists()。

预防：全项目 here()，打开 .Rproj 而不是双击脚本。

更多同类报错见 R 代码急救室。

padj 控制的是发现集的错误比例，不是效应大小。padj = 0.01、log2FC = 0.3 可以统计显著但生物学意义有限；要结合效应量、CI、表达丰度与通路一致性。反过来，LFC 很大但 padj 不显著，也不能写「趋势显著」。

本章的 DE 结果、火山图与富集图由同一份 counts、同一 design、同一次 DESeq 运行生成；示例在独立 R 进程中执行，输出由 check-examples.R 逐字校验。

Differential expression was tested with DESeq2 (negative-binomial GLM, design ~ group; batch could not be included because it was completely confounded with treatment), with low-count genes filtered (counts ≥ 10 in at least 6 samples) and log2 fold changes shrunk with apeglm; genes were called at padj < 0.05 and |log2FC| > 1 (49 up, 5 down), and KEGG over-representation used the tested genes as background; no pathway passed FDR 0.05.

中文：用 DESeq2（负二项 GLM，design ~ group；batch 与处理完全重合，无法纳入）检验差异表达，过滤低表达基因（至少 6 个样本 counts ≥ 10），用 apeglm 收缩 log2FC；以 padj < 0.05 且 |log2FC| > 1 选出 49 上调、5 下调；KEGG 过表达富集以可检验基因为背景，没有通路通过 FDR 0.05。

小结

DE 五步：设计可估计 → 过滤/归一化 → 负二项模型 → 收缩 + FDR/效应量双阈值 → 富集（背景正确）。完全混杂时只能报告限制；富集为空就写「未发现」。基因列表不是结论，效应量与设计才是。
