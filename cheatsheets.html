图形质检清单

投稿前逐项检查：n、单位、误差线、统计标注、可读性。

  1. 1. n：每个组标出样本量（或图注写明）。
  2. 2. 单位：两个轴都有单位；图例说明变量。
  3. 3. 误差：写清 SD / SE / 95% CI，并在图注说明。
  4. 4. 统计：检验名、p 值或效应量写在图注，不写在图上。
  5. 5. 可读：字号 ≥ 7 pt（终稿尺寸）；色盲安全；黑白可辨。
  6. 6. 一致性：所有图的主题、字号、配色统一。
检查项不合格示例修正
n只有均值柱，没有 n加 n 或图注写 n/组
误差线标了误差但没说是 SD 还是 SE图注写明

  • 图注 = 图的自解释说明书：n、统计、误差、软件版本。

统计检验选择

结局类型 × 设计 × 前提 → 检验与 R 函数；一页对齐统计导航。

  1. 1. 结局是什么：连续、二分类、有序、计数、时间到事件？
  2. 2. 几组、独立还是配对？组数 ≥ 3 先整体检验。
  3. 3. 前提：分布形状、方差齐性、独立性；不满足就换非参数或建模。
  4. 4. 报告：效应量 + 95% CI；多重比较要校正。
设计结局推荐检验R 函数
两组独立连续Welch tt.test(y ~ g)
两组配对连续配对 tt.test(x, y, paired = TRUE)
三组以上连续ANOVA + 事后aov(); TukeyHSD()
偏态/有序连续/有序Wilcoxon / Kruskalwilcox.test(); kruskal.test()
两组/多组二分类卡方 / Fisherchisq.test(); fisher.test()
时间到事件生存log-rank / Coxsurvdiff(); coxph()
  • 三组两两 t 检验会抬高假阳性；先整体再事后。
  • 配对设计不能用独立样本检验；n 是个体数。
CH11CH12CH16 检验由设计与结局决定，不由 p 值决定。

样本量与功效

pwr、效应量、α、power 与模拟——n 不是拍脑袋定的。

  1. 1. 明确结局与检验（t / ANOVA / 比例 / 生存）。
  2. 2. 定效应量：来自预实验、文献或最小临床意义差。
  3. 3. 定 α（0.05）与 power（0.8）。
  4. 4. 算 n；再算「给定 n 能检出多大效应」。
  5. 5. 敏感性分析：效应量减半时 n 需要多少？
场景函数关键参数
两组均值pwr.t.test()d、sig.level、power
多组均值pwr.anova.test()k、f、sig.level、power
两组比例pwr.2p.test()h、sig.level、power
相关pwr.r.test()r、sig.level、power
模拟法replicate + 检验自己造数据估检出率
  • 功效分析必须在收数据前做。
  • 观测到的 p 值不能反推功效（post-hoc power 是循环论证）。
