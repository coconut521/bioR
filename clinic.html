红旗速筛

六个是非题，全部来自下面的真实病例。答「否 / 不确定」会推荐对应病例；这不是评分，只是一次体检。

1你的 n 是独立生物学个体吗（而不是细胞、孔或切片）？

2处理组与对照组是否都覆盖了多个批次？

3三组以上比较时，是否做了整体检验与多重比较校正？

4排除/清洗规则是否在看结果之前就已确定？

5图是否由代码从数据直接生成（而不是手工改图）？

6报告是否包含效应量与 95% CI（而不只是 p 值）？

设计 CASE 01

30 个细胞来自 3 只鼠，n 是多少？

症状
处理组 15 个细胞 vs 对照组 15 个细胞，t 检验 p = 0.001，结论「处理显著」。
红旗
把细胞、孔或切片当成独立生物学重复。
诊断
细胞嵌套在个体内；以细胞为 n 会低估误差、放大自由度，p 值被虚假压低。
处方
  1. 统计单位是个体：先按 mouse 汇总，每组 n = 3
  2. 或用混合模型，把 cell 嵌套于 mouse
  3. 图和表报告个体数 n，而不是细胞数
R 修复
library(lme4)
m <- lmer(value ~ group + (1 | mouse), data = d)
summary(m)

预防实验设计时先写下统计单位、生物学重复数与技术重复数。

设计 CASE 02

处理组全在批次 1，对照组全在批次 2

症状
PCA 上两组完全分开，差异基因上千；结论「处理效应很强」。
红旗
处理与批次完全重合，效应无法分离。
诊断
批次是混杂变量；模型里加 batch 会与 group 共线，参数无法估计。
处方
  1. 重做实验：每组跨批次并随机化
  2. 若无法重做，只能把结论降级为「批次/处理混合效应」
  3. 记录批次，在下次设计中分层
R 修复
# 设计阶段随机化，而不是事后建模补救
set.seed(1)
assign <- sample(rep(c("ctrl", "trt"), each = 3))

预防上机/建库前按批次分层随机化，确保每组覆盖多个批次。

统计 CASE 03

p = 0.06，再补 3 个样本，p = 0.04

症状
第一次分析 p = 0.06；补到 n = 13 后 p = 0.04，报告「显著」。
红旗
看到结果后继续加样本（可选停止），未做校正。
诊断
反复看结果、多次检验会抬高 I 类错误；最终 p 不是预先设计下的 p。
处方
  1. 预先定样本量与停止规则
  2. 报告全部阶段与所有检验
  3. 把补样本后的结果标为探索性
R 修复
# 事前做功效分析，而不是事后补样本
library(pwr)
pwr.t.test(d = 0.8, power = 0.8, sig.level = 0.05)

预防分析计划先写死 n、主要终点与停止规则。

统计 CASE 04

20 个基因逐个 t 检验，3 个 p < 0.05

症状
20 个基因分别做两组 t 检验，3 个 p < 0.05，挑出来当「差异基因」。
红旗
多重比较未校正，且只报告显著者。
诊断
20 次检验期望约 1 个假阳性；未校正的 p 不能作为基因列表依据。
处方
  1. BH/FDR 校正：p.adjust(p, method = "BH")
  2. 或统一模型（limma / DESeq2）
  3. 报告全部基因与校正阈值
R 修复
p <- c(0.01, 0.04, 0.03, 0.2, 0.6)
p_adj <- p.adjust(p, method = "BH")
data.frame(p, p_adj)

预防分析前定好检验家族与 FDR 阈值。

统计 CASE 05

血红蛋白右偏，直接做 t 检验

症状
两组血红蛋白分布右偏、各有离群值；t 检验 p = 0.03，报告均值差。
红旗
未看分布就选 t 检验，并用均值概括偏态数据。
诊断
t 检验对偏态与离群值敏感；小样本下方差估计不稳。
处方
  1. 先画分布/QQ；偏态用中位数(IQR)
  2. 改用 Wilcoxon 秩和或对数变换
  3. 报告效应量与 CI
R 修复
wilcox.test(hb ~ group, data = d, conf.int = TRUE)

预防描述统计前先看图，按分布形状选检验。

统计 CASE 06

先看 p 值，再决定删哪个离群值

症状
初版 p = 0.08；删掉 1 个「离群点」后 p = 0.03，报告后者。
红旗
排除规则在看到结果之后才定。
诊断
事后排除会制造想要的结论；p 值不再可信。
处方
  1. 预设离群规则（技术原因或 |z| > 3）
  2. 报告敏感性分析：删/不删两种结果
  3. 保留原始数据与排除日志
R 修复
d$outlier <- abs(scale(d$value)) > 3
# 报告 with / without
t.test(value ~ group, data = d)
t.test(value ~ group, data = subset(d, !outlier))

预防数据清理规则在揭盲/看结果前写进分析计划。

可视化 CASE 07

柱状图 + SEM，看起来两组差很多

症状
柱高表示均值，误差线 SEM；n = 3，读者以为差异很大。
红旗
柱状图掩盖分布；SEM 不是 95% CI。
诊断
柱形把数据压缩成均值，隐藏偏态/离群；SEM 随 n 缩小，容易误导。
处方
  1. 改箱线图/点图/雨云图，显示每个点
  2. 误差线用 95% CI 并标 n
  3. 图注写清统计量定义
R 修复
library(ggplot2)
ggplot(d, aes(group, value)) +
  geom_boxplot(width = .4, outlier.shape = NA) +
  geom_jitter(width = .08, alpha = .6)

预防先画原始点，再决定是否叠加汇总。

统计 CASE 08

三组两两 t 检验，挑出显著的一对

症状
低/中/高三组做 3 次 t 检验，只有低 vs 高 p < 0.05，结论「低海拔与高海拔不同」。
红旗
三组以上未做整体检验与多重校正。
诊断
多次两两比较抬高假阳性；缺少整体模型。
处方
  1. 先做 ANOVA / Kruskal 整体检验
  2. 事后用 Tukey / Dunn 校正
  3. 报告整体 p 与校正后的两两 p
R 修复
m <- aov(value ~ group, data = d)
summary(m)
TukeyHSD(m)

预防组数 ≥ 3 时先定整体检验与事后方法。

统计 CASE 09

把分组相关当个体相关

症状
按海拔组算均值，发现「海拔越高 Hb 越高」；个体层面却几乎无关。
红旗
用组均值推断个体（生态学谬误 / Simpson）。
诊断
组间趋势与组内趋势可能相反；聚合会丢失个体变异。
处方
  1. 个体层面建模，结论只针对个体
  2. 组均值趋势仅作描述，不用于个体推断
  3. 需要组效应时用足够组数的混合模型
R 修复
lm(hb ~ altitude, data = d)              # 个体层面
aggregate(hb ~ altitude_group, d, mean)  # 组层面，仅描述

预防明确推断层级：结论针对个体还是组。

统计 CASE 10

有序评分当连续变量做线性回归

症状
疼痛评分 0–4 直接 lm，报告「每升 1 分疼痛增加 …」。
红旗
有序分类被当成等距连续变量。
诊断
等级间距不一定相等；线性模型假设不成立。
处方
  1. 有序模型（累积链接）或非参数检验
  2. 报告中位数与分布
  3. 不要解释「每 1 分」的线性斜率
R 修复
library(MASS)
polr(factor(score, ordered = TRUE) ~ group, data = d, Hess = TRUE)

预防变量的测量尺度决定模型类型。

统计 CASE 11

生存分析把删失样本删掉

症状
到终点仍存活的个体被剔除，KM 曲线下降更快，组间 p 更小。
红旗
删失被当作缺失删除。
诊断
删失个体仍提供「至少活到某时」的信息；删除造成选择偏倚。
处方
  1. 保留删失：Surv(time, event)
  2. KM 曲线 + log-rank；Cox 报告 HR/CI
  3. 说明删失原因与比例
R 修复
library(survival)
fit <- survfit(Surv(time, event) ~ group, data = d)
plot(fit)
survdiff(Surv(time, event) ~ group, data = d)

预防随访数据记录事件/时间/删失原因，分析时全部纳入。

组学 CASE 12

原始 counts 直接 PCA，第一轴是批次

症状
PCA 第一轴把样本按建库批次分开，却被解释为「处理效应」。
红旗
未做表达量变换/归一化，技术偏差主导。
诊断
counts 方差随均值增长，高表达基因支配 PCA；批次未校正。
处方
  1. logCPM / VST 稳定方差
  2. PCA 前检查批次并校正（removeBatchEffect）
  3. 用归一化后的矩阵
R 修复
library(edgeR)
lcpm <- cpm(y, log = TRUE)
pca <- prcomp(t(lcpm), scale. = TRUE)

预防组学分析先归一化/变换，再看整体结构。

统计 CASE 13

n = 10，8 个预测变量

症状
R² = 0.92，所有预测变量显著；新样本预测一塌糊涂。
红旗
样本量远小于变量数，未做验证。
诊断
过拟合：模型记住噪声；系数与 p 值不稳定。
处方
  1. 减少变量或先降维（PCA）
  2. 正则化（ridge / lasso）
  3. 交叉验证评估预测
R 修复
library(glmnet)
cv.glmnet(x, y, alpha = 1)  # lasso + CV

预防先算样本量/事件数，再定变量上限；预注册主要模型。

可复现 CASE 14

图是手改的，报告不可重跑

症状
PPT 里把误差线拉长、颜色改掉；换数据后图没更新。
红旗
图与数据脱节，无代码、无版本。
诊断
手工编辑不可复现，审稿/复审无法追溯。
处方
  1. 图由 R 脚本生成，数据和代码同版本
  2. Quarto/Rmd 一键渲染
  3. 导出 SVG/PDF 并记录 sessionInfo
R 修复
library(ggplot2)
p <- ggplot(d, aes(group, value)) + geom_boxplot()
ggsave("fig/fig1.svg", p, width = 89, height = 55, units = "mm")

预防从第一张图开始就用代码生成，禁止手工改图。
