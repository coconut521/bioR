外部开放数据入口

只给入口与检索策略，本站不镜像、不自动下载外部数据；引用与许可按各站点要求执行。

表达谱

GEO · Gene Expression Omnibus

适合：找同主题的芯片/RNA-seq 数据集与样本表。

许可注意：数据多可自由使用，但样本级信息需遵守原文与伦理限制。

引用：引用数据集编号（GSExxx）与原文。

打开 GEO工具：GEOquery / readr
原始测序

SRA · Sequence Read Archive

适合：下载 fastq 重跑上游流程（ch17 的前一站）。

许可注意：受控访问数据（dbGaP）不可用于公开教学。

引用：SRP/SRR 编号 + BioProject。

打开 SRA工具：SRA Toolkit
基因组/注释

Ensembl

适合：取参考基因组、GTF 注释与同源基因。

许可注意：数据开放，遵守站点引用要求。

引用：Ensembl release 版本号 + 物种。

打开 Ensembl工具：biomaRt / AnnotationHub
蛋白

UniProt

适合：查蛋白功能、结构域与通路注释。

许可注意：CC BY 4.0，注明版本。

引用：UniProtKB 登录号 + release。

打开 UniProt工具：UniProt.ws
结构

PDB · Protein Data Bank

适合：取蛋白结构做结构域映射与图。

许可注意：结构数据开放（CC0），图件署名规范见站点。

引用：PDB ID + 原文。

打开 PDB工具：bio3d / PyMOL
通路

KEGG

适合：通路图与富集分析的背景集。

许可注意：学术使用需遵守 KEGG 的使用条款（商业用途需授权）。

引用：KEGG release + 通路编号（ko/k map）。

打开 KEGG工具：clusterProfiler
物种分布

GBIF

适合：高原鼠兔等物种的分布记录与生态分析。

许可注意：各记录许可不同（CC0/CC BY/CC BY-NC），逐条查看。

引用：GBIF DOI + 数据集引用。

打开 GBIF工具：rgbif
原始数据仓库

Dryad

适合：找论文背后的原始数据与代码包。

许可注意：多为 CC0，仍以数据集页面为准。

引用：Dryad DOI（数据引用与论文引用分开写）。

打开 Dryad工具：浏览器 + readr

另有 ArrayExpress、UCSC Genome Browser、GO Consortium、Zenodo、Figshare 等入口，检索策略相同：先读许可与版本，再下载。

教学模拟数据必须标注 simulated: true：任何用了本章数据的作业、报告、预注册，都要写明「模拟数据，固定种子 20261027，仅用于教学」。

  • 真实数据必须写许可与来源；本站不收录患者级数据。
  • 外部数据不镜像、不自动抓取；下载文件名与数据字典保持一致。
  • 数据字典是数据卡的一部分，引用时一并提供。
