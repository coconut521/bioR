# 01 · 视觉设计系统

参考对象：`cpp_website/v2` 的「编辑部正文 + 代码实验台 + 学习地图」。本文件把它转译为生物科研 R 教学站的设计语言。所有实现必须使用这里的令牌，不要在页面里硬编码颜色、字号或阴影。

---

## 1. 设计方向

一句话：**一本可以操作的田野笔记**。

- **阅读面**：纸/墨色、细线、大量留白，像一本印刷的科研手册。
- **操作面**：代码 Listing 是「实验台」，有标题栏、工具条、输出终端和图形舞台。
- **导航面**：首页是一条研究路线，不是功能菜单。
- **专题面**：每个专栏有自己的隐喻（图鉴、航线图、诊室、急救室、标本馆、工作台），但共享同一套纸面组件。
- **品牌色**：R 蓝只用于链接、当前状态、进度和关键强调；大面积永远是纸色。苔绿表示「生物学上成立 / 已完成」，橙色表示「需要判断」，红色只给错误与危险。

不要做成 SaaS 仪表盘：没有大色块、没有霓虹渐变、没有卡片阴影堆叠、没有 3D 图表。

## 3. 排版

### 3.1 字族

- **正文 / 标题**：`--bio-sans`。中文优先 PingFang / 微软雅黑 / Noto Sans CJK。
- ** Hero 强调与章节大号数字**：`--bio-serif`，斜体只用于 Hero 的一个词，不用于正文。
- **代码 / kicker / 标签 / 行号 / 图注编号**：`--bio-mono`。

**关键决策：图中的坐标轴、图例、统计标注使用英文**，网页正文和图表说明使用中文。原因：
1. 期刊图通常要求英文；
2. 不同系统缺少中文字体时，SVG/PDF 中的中文会变成方框；
3. 教学重点是把「图」和「论文」连起来，而不是做中文信息图。

### 3.2 字号阶梯

| 用途 | 大小 | 行高 | 字重 |
| --- | --- | --- | --- |
| Hero 标题 | `clamp(2.6rem, 5vw, 4.3rem)` | 1.02 | 760 |
| 章节标题 h1 | `clamp(2rem, 3.2vw, 2.7rem)` | 1.15 | 700 |
| 节标题 h2 | 1.5rem | 1.3 | 700 |
| 小节 h3 | 1.15rem | 1.4 | 650 |
| 正文 | 1rem（16px） | 1.8 | 400 |
| 辅助文字 | .88rem | 1.65 | 400 |
| Kicker | .7rem | 1.4 | 700，字距 .18em |
| 代码 | .88em | 1.65 | 400 |
| 图注 | .8rem | 1.6 | 400 |

正文最大阅读宽度 **72–78 个字符**（约 780px 栏宽）。中文段落行高不低于 1.8。

### 3.3 排版细节

- 标题使用 `letter-spacing: -.015em`；Hero 用 `-.04em`。
- 段落 `text-wrap: pretty`；标题 `text-wrap: balance`。
- 数据表使用 `font-variant-numeric: tabular-nums`。
- 中文与英文/数字之间保留自然空格（作者手写，不用 JS 自动插入）。
- 不使用首行缩进；段间距 `.65em`。
- 强调用 `<b>`，术语首次出现加粗；不要整段加粗。
- 引用块用于「论文原句 / 方法学句式」，左侧 2px 蓝线。

## 4. 布局

### 4.1 全局栅格

```text
Header:  max-width 1380px, height 64px, sticky
Home:    max-width 1180px
Chapter: max-width 1440px
         [ reading 780px ] [ gap 56px ] [ rail 250–330px ]
Special: max-width 1200px, 2–4 列卡片
Print:   A4, 单栏
```

### 4.2 章节页

- 封面横跨两栏（`grid-column: 1 / -1`）。
- 正文在左栏，右栏 sticky（`top: header + 18px`），自身可滚动。
- 右栏顺序：本章科研问题卡 → 田野笔记 → 小节索引 → 工具。
- 平板（≤1024px）：正文 680px + 右栏 290px；右栏内部变两列。
- 手机（≤768px）：右栏折叠为「本章导航」抽屉；正文单栏。
- 任何宽度下，代码块和表格允许内部横向滚动，但**页面本身不允许横向滚动**。

### 4.3 首页

- Hero 两栏：左文案 + 右「继续上次 / 今日任务」。
- 研究路线：4 个阶段，每阶段一条横向路线；桌面 4 列，平板 2 列，手机 1 列。
- 专题航线：7 张卡片，桌面 4 列（第一行 4、第二行 3），平板 2 列，手机 1 列。
- 底部三栏：课题工作台摘要 / 最近更新 / 术语与搜索。

### 4.4 间距

4px 基准：4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 / 96。章节节间距 56–72px；卡片内部 16–20px；代码块与说明之间 14px。

## 5. 组件规范

### 5.1 顶栏

- 高 64px，半透明纸色 + `backdrop-filter: blur(14px)`，底部 1px 细线。
- 左：34px 方形 logo，`R` 字，R 蓝底；品牌两行：`bioR` / `R FOR BIOLOGY`。
- 中：首页 / 课程 / 绘图 / 生信 / 速查 / 更多。
- 右：搜索按钮（`Ctrl K`）、主题、字号、演示模式。
- 当前页用底部 2px 蓝线，不加背景块。
- 手机：品牌 + 搜索 + 课程抽屉，其他进「更多」。

### 5.2 章节封面

```text
CHAPTER 06 · DATA WRANGLING                    ————————————————
[ 06 ]   把 60 只鼠兔整理成一张能分析的表
         本章科研问题：不同海拔种群的体重差异是否真实存在？
         45 min · 前置 ch05 · 数据 pika_physiology.csv · 交付 table1_group.csv
         [ 标记完成 ] [ 下载本章脚本 ] [ 打印 ]
         ← 上一章                         下一章 →
         学习目标（两列，带掌握度标记）
```

- 左侧大数字用描边 serif，颜色 `--bio-blue`，透明度 .55。
- 封面上下各 1px 细线，不使用背景色块。
- 元信息用 mono 小字，图标 14px。
- 学习目标每项前一条 7px 蓝线；已掌握项变灰；未知项左侧红条。

### 5.3 右栏

- 宽 250–330px，左边 1px 细线，左内边距 22px。
- 「本章科研问题」卡：白面、1px 线、顶部 3px 蓝线；问题正文 0.9rem；下面一个「打开讲解器」按钮。
- 田野笔记：每条左侧 2px 透明线，hover 变纸色，当前项变蓝底线 + 浅蓝背景。
- 小节索引：当前项左侧 2px 蓝线 + 浅蓝渐变；编号 mono。
- 工具：2×2 网格，小按钮。
- 窄屏折叠时，按钮文案为「本章导航」。

### 5.4 Listing（代码卡）

```text
┌ LISTING 06.2 · wrangle.R · 18 lines ──────────────── [复制] [下载] [输出] ┐
│ 01  pika |>                                                             │
│ 02    group_by(altitude_group) |>                                       │
│ ...                                                                     │
├─ R console ─────────────────────────────────────────────────────────────┤
│ > pika |> group_by(...) |> summarise(...)                               │
│ # A tibble: 3 × 2                                                       │
└─────────────────────────────────────────────────────────────────────────┘
```

- 头部：mono 小字，左侧编号 + 文件名 + 行数；右侧工具按钮。
- 代码区：深色底，行号由 CSS counter 生成，`user-select: none`；当前讲解步骤行加左侧 2px 蓝线和浅蓝底。
- 输出终端：独立深色块，顶部一条 `R console` 标签；提示符 `>` 与输出用不同灰度。
- 工具：复制、下载 `.R`、显示/隐藏输出、单步、在 RStudio 中打开（复制 `file.show()` 命令，不做协议跳转）。
- 代码块内的 `<`、`>`、`&` 必须转义。
- 代码块不换行；横向滚动，滚动条细。

### 5.5 图形舞台

```text
┌ 图 8.2 · 不同海拔的体重分布 ─────────────────────────── [SVG] [PDF] ┐
│                                                                    │
│                        （R 预渲染图）                               │
│                                                                    │
├ 图注 ───────────────────────────────────────────────────────────────┤
│ 箱线图叠加个体点；n = 20 / 20 / 20；误差线为 IQR。                  │
│ [ 查看绘图代码 ]  [ 这张图回答了什么 ]                              │
└────────────────────────────────────────────────────────────────────┘
```

- 图由 R 脚本预渲染为 SVG（复杂图可 PNG 2x 回退），存放在 `assets/figures/`。
- 图片必须有 `alt`，描述图的**结论**而不是「一张图」。
- 图注格式：`图 8.2 · 标题` + 一句结论 + `n` + 统计/误差线定义。
- 提供「查看绘图代码」折叠块；代码与图同源。
- 提供出版版 PDF 下载（89mm 或 183mm）。
- 图内文字英文，图注中文。

### 5.6 数据预览

- 顶部：数据集名、行×列、来源、下载按钮。
- 表头 sticky，类型行（`<dbl>`、`<fct>`、`<chr>`）用 mono 小字。
- 只显示前 6–10 行；「查看数据字典」打开抽屉/折叠。
- 缺失值显示为 `NA` 徽标；重复 ID 用红色左边线标记（教学场景）。
- 表格容器可横向滚动，页面不滚动。

### 5.7 讲解器

每个讲解器只回答一个具体问题，标题写在卡片顶部：

| 引擎 | 回答的问题 | 画面 |
| --- | --- | --- |
| `vector` | 这个向量里到底存了什么？ | 单元格、类型、`NA`、强制转换箭头 |
| `dataframe` | 一行是不是一个样本？ | 表格行列、类型、重复 ID 高亮 |
| `pipeline` | 每一步之后数据长什么样？ | 阶段条 + 行数/列数变化 |
| `plot-grammar` | 这一层给图加了什么？ | 图层堆叠：data → aes → geom → stat → scale → facet → theme |
| `stats` | 这个 p 值是怎么来的？ | 抽样分布、效应量、拒绝域 |
| `matrix` | 样本为什么聚在一起？ | 矩阵热图 → PCA 投影/聚类树 |
| `timeline` | 事件在时间上怎么发生？ | 生存时间线、删失、风险集 |

交互：首帧 / 上一帧 / 下一帧 / 播放暂停 / 速度 / 末帧。默认暂停，不自动播放。打印时自动到末帧。

### 5.8 提示块

| 类 | 用途 | 视觉 |
| --- | --- | --- |
| `.note` | 补充说明 | 纸色底 + 左蓝线 |
| `.tip` | 实操建议 | 浅绿底 + 左绿线 |
| `.warn` | 需要判断 | 浅橙底 + 左橙线 |
| `.danger` | 错误/危险 | 浅红底 + 左红线 |
| `.research` | 田野笔记 / 科研情境 | 纸色底 + 虚线边框 + 蓝色图钉图标 |
| `.stats` | 统计判断 | 浅蓝底 + 左蓝线 + `STATS` kicker |
| `.repro` | 可复现提醒 | 浅绿底 + `REPRO` kicker |

标题由组件自动生成，作者不手写「注意：」。

### 5.9 对比块

两列：左「常见错误 / base R」，右「推荐写法 / tidyverse」。左列顶部红线，右列顶部绿线。移动端上下堆叠。用于：
- base R vs tidyverse；
- 错误统计 vs 正确统计；
- 原始图 vs 出版图。

### 5.10 测验

- 题型：`mcq`、`tf`、`fill`、`mfill`、`code`、`plot`。
- 一题一卡；选项用整行按钮；选中后显示解释，不用弹窗。
- 顶部显示进度 `3 / 8`；底部「重新开始」。
- 答案默认隐藏；教师模式可一键显示。
- 统计题必须给单位、n、设计；不出「p<0.05 所以因果成立」这类题。

### 5.11 速查卡

- 卡盒布局，每张卡顶部编号 + 标题 + 分类标签 + 复制按钮。
- 表格型、代码型、条目型、决策型四种。
- 科研工具卡加 `RESEARCH TOOL` 徽标（苔绿）。
- 支持搜索、分类筛选、直达按钮、打印。
- 打印时每张卡 `page-break-inside: avoid`。

### 5.12 搜索命令面板

- `Ctrl/Cmd + K` 打开；全屏遮罩 + 居中面板。
- 分组：章节 / 速查 / 专栏 / 术语 / 数据集。
- 键盘：↑↓ 选择，Enter 打开，Esc 关闭。
- 搜索中文子串 + 英文 token；不依赖网络。
- 无结果时给「试试：t 检验 / 热图 / join / DESeq2」。

### 5.13 进度与状态

- 进度环用于首页与课题工作台；章节用「已学完」按钮。
- 状态色：未开始（细线圆）、进行中（蓝环）、已完成（绿底勾）。
- 掌握度：`知道` / `不确定` / `不知道` 三态，存 `bior.mastery`。
- 不用红色表示「未完成」，红色只给错误。

## 6. 图标与插图

- 图标：内联 SVG，24×24 viewBox，`stroke-width: 1.6`，`currentColor`，圆角端点。
- 不使用 emoji 作为功能图标；emoji 只允许出现在专栏卡片的「隐喻」位置，且必须同时有 SVG 图标。
- 插图：优先 HTML/CSS/SVG 手绘，不引入外部图片。
- 统计示意图（分布、PCA、生存曲线）可以由 R 预渲染，但示意图（流程、层级）用 SVG 手写，便于深色模式换色。
- 所有装饰性 SVG 加 `aria-hidden="true"`；信息性 SVG 加 `<title>` 和 `<desc>`。

---

## 7. 动效

- 时长 120–200ms；缓动 `ease` 或 `cubic-bezier(.2,.7,.3,1)`。
- 只用于：hover、展开/折叠、讲解器换帧、搜索面板、抽屉。
- 不自动播放讲解器；不做视差；不做循环动画。
- `prefers-reduced-motion: reduce` 时关闭过渡与自动播放，讲解器仍可手动单步。
- 打印时禁用动效。

---

## 8. 无障碍

目标：WCAG 2.1 AA。

- 正文与背景对比度 ≥ 4.5:1；大字号 ≥ 3:1。
- 焦点可见：2px 蓝线 + 3px offset；不用 `outline: none`。
- 所有交互可键盘完成：搜索、讲解器、测验、抽屉、标签页。
- 跳过导航链接：`跳到正文`。
- 表格：`<caption>`、`<th scope>`；不把表格用于布局。
- 图片：`alt` 描述结论；装饰图 `alt=""`。
- 颜色不是唯一编码：分组同时用颜色 + 形状/线型；状态同时用图标 + 文字。
- 图表配色默认色盲安全（Okabe–Ito / viridis），不用彩虹色。
- 动画尊重 `prefers-reduced-motion`。
- 表单错误用文字说明，不只变红。
- 打印版保留可读的标题层级与图注。

---

## 9. 打印

- A4，页边距 18mm；隐藏顶栏、右栏、工具条、搜索、测验按钮。
- 章节封面单独一页；正文从新页开始。
- 讲解器打印末帧；代码 Listing 打印当前完整代码与输出。
- 图占满栏宽，保留图注；分页避免图与图注分离。
- 表格字号 8.5–9pt；代码 8pt；正文 10.5pt。
- 链接显示为黑色，不显示 URL（站内链接无意义）。
- 页脚：`bioR · 章节标题 · 页码`。

## 10. 响应式断点

| 断点 | 行为 |
| --- | --- |
| ≥1280px | 完整三栏/两栏布局；右栏 sticky |
| 1024–1279px | 正文 680px + 右栏 290px；首页专题 2 列 |
| 768–1023px | 右栏折叠为顶部「本章导航」；首页路线 2 列 |
| <768px | 单栏；代码/表格内部滚动；隐藏大数字；搜索全屏 |
| <480px | 字号降至 15px；按钮全宽；图注字号 .78rem |

触摸目标最小 44×44px。移动端不显示 hover-only 信息。

## 11. 反模式清单

- ❌ 紫色/彩虹渐变、玻璃拟态、霓虹发光。
- ❌ 每张卡片都加阴影；正文卡片只用细线。
- ❌ 用 emoji 代替图标体系。
- ❌ 图中使用彩虹配色或红绿唯一编码。
- ❌ 3D 饼图、双 Y 轴（除非明确说明并给出理由）。
- ❌ 柱状图 + 误差线掩盖分布（默认用箱线+散点或雨云图）。
- ❌ 在网页里手写「预期输出」而不跑脚本。
- ❌ 用 `p < 0.05` 作为唯一结论。
- ❌ 把 `setwd("C:/Users/...")` 写进教学代码。
- ❌ 在正文里放大段控制台报错截图（应使用可复制的错误卡）。
