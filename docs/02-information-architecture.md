# 02 · 信息架构与页面类型

本文件定义站点有哪些页面、每页承担什么任务、用户如何移动，以及所有页面共享的导航、搜索、进度与元数据规则。

---

## 1. 用户与任务

| 用户 | 典型问题 | 首站 | 成功标准 |
| --- | --- | --- | --- |
| 生物本科生 | 「我只会 Excel，能不能学会 R 做实验数据分析？」 | 首页研究路线 → ch01 | 完成前 6 章，能独立整理一张样本表 |
| 研究生 | 「我要做 qPCR / 生理数据 / RNA-seq，怎么选检验、怎么画图？」 | 首页 → 统计导航 / 绘图专区 | 找到对应章节与代码模板，能复现图 |
| 实验科研人员 | 「这个 R 报错什么意思？这个分析设计有没有问题？」 | 代码急救室 / 数据诊所 | 3 分钟内定位原因与修复 |
| 导师 / 教师 | 「我要按课时组织教学，或给学生布置任务」 | 课程路线 / 课题工作台 | 按章节和交付物组织教学 |

设计含义：
- 首页必须同时服务「从头学」和「带着问题来查」两类人。
- 每章必须有「科研任务 + 交付物」，而不是只有知识点。
- 所有查询型页面（速查、急救、统计导航、绘图、生信）必须能从顶栏 1 次点击到达。

## 3. 全局导航

### 3.1 顶栏

| 位置 | 内容 | 行为 |
| --- | --- | --- |
| 左 | Logo `R` + `bioR` + `R FOR BIOLOGY` | 回首页 |
| 中 | 首页 / 课程 / 绘图 / 生信 / 速查 / 更多 | 当前页高亮 |
| 右 | 搜索（`Ctrl K`）、主题、字号、演示 | 全局可用 |

「更多」下拉：数据诊所、统计导航、代码急救室、数据集标本馆、课题工作台、术语表、关于。

移动端：
- 顶栏只留 Logo、搜索、菜单。
- 菜单打开全屏抽屉，分组：课程 / 专栏 / 参考 / 工作台。
- 抽屉内显示当前章节进度与「继续学习」。

### 3.2 页脚

四栏：
1. `bioR` 一句话 + 设计来源说明。
2. 课程：前 6 章 + 全部章节。
3. 专栏：绘图、生信、诊所、统计导航、急救、数据集。
4. 参考：速查、术语、课题工作台、更新日志。

底部：`内容为教学模拟数据，不构成临床或科研结论` + `离线可用 · 无追踪`。

### 3.3 章节 pager

每章底部：上一章 / 章节索引 / 下一章。显示章节号、标题、一句话目标。首页与专栏页不显示章节 pager。

## 4. 页面类型

### 4.1 首页（研究路线）

**任务**：30 秒内回答「这是什么、从哪开始、我上次学到哪、我能查到什么」。

```text
┌ Hero ───────────────────────────────────────────────────────────────┐
│ kicker: R FOR BIOLOGY · FROM BENCH TO FIGURE                        │
│ h1: 把 R 学成一条                                             [继续] │
│     从实验台到论文图的路线。                                        │
│ lede: 18 章、7 个专栏、36 速查表。每一章解决一个真实科研问题。       │
│ [ 搜索章节/报错/速查/术语  Ctrl K ] [ 进入研究路线 → ]              │
│ stats: 18 章 · 7 专栏 · 36 速查 · 9 数据集                          │
└─────────────────────────────────────────────────────────────────────┘
┌ 研究路线 ───────────────────────────────────────────────────────────┐
│ 阶段 I 准备数据   ●──●──●──○──○   ch01–ch05                        │
│ 阶段 II 探索       ○──○──○──○      ch06–ch09                        │
│ 阶段 III 推断      ○──○──○──○      ch10–ch13                        │
│ 阶段 IV 交付       ○──○──○──○──○   ch14–ch18                        │
│ [章节卡：编号 / 标题 / 科研问题 / 交付物 / 时长]                    │
└─────────────────────────────────────────────────────────────────────┘
┌ 今日任务 ─────────────┬ 课题工作台摘要 ────────┬ 最近更新 ──────────┐
│ 下一章 + 为什么现在学  │ 交付物 6/18 · 图 1/4    │ 新章节/新速查       │
└───────────────────────┴───────────────────────┴────────────────────┘
┌ 专题航线（7 张卡） ─────────────────────────────────────────────────┐
│ 绘图图鉴 / 生信航线 / 数据诊所 / 统计导航 / 代码急救 / 标本馆 / 工作台│
└─────────────────────────────────────────────────────────────────────┘
┌ 搜索与术语 ─────────────────────────────────────────────────────────┐
│ 常用术语 chips：p 值、FDR、PCA、tibble、join、DESeq2、删失…          │
└─────────────────────────────────────────────────────────────────────┘
```

首页不使用轮播、不用营销式大图。Hero 右侧是功能性的「继续上次 / 今日任务」，不是装饰插画。

### 4.2 章节页

**任务**：在一个连续科研情境里教一个语法/统计能力，并产出一个可保存的交付物。

固定顺序：

1. **封面**：章节号、标题、本章科研问题、时长、前置、数据集、交付物、完成按钮、上下章。
2. **学习目标**：4–6 条，可标记掌握度。
3. **研究情境**（`.research`）：一段 80–150 字的真实场景，说明「为什么现在需要这个技能」。
4. **正文小节**：每节一个 `<h2>`，含：
   - 概念解释；
   - 1–3 个 Listing；
   - 至少一个图/表/讲解器；
   - base R / tidyverse 对照（如适用）。
5. **科研任务**（`.research` + 步骤列表）：学生按步骤操作自己的数据，产出交付物。
6. **常见错误**（`.danger` 卡片组）：R 报错原文 → 原因 → 修复。
7. **科研判断**（`.stats`）：这一章涉及的统计/设计判断，3–5 条。
8. **方法学一句话**：可直接放进论文 Methods 的英文句式 + 中文解释。
9. **小结**（`.keypoint`）：5–7 条。
10. **自测**：6–8 条 checklist + 6–10 题 quiz。
11. **研究日志**：本章交付物、保存路径、下一章如何使用它。
12. **延伸**：相关速查表、专栏、数据集。
13. Pager。

右栏固定：
- 本章科研问题卡（点击滚动到研究情境）。
- 田野笔记（每条对应一个小节）。
- 小节索引。
- 工具：复制全部代码、下载本章脚本、打印、标记完成。

**章节页的「一页只回答一个科研问题」原则**：封面问题必须能用一句话回答；如果一章需要两个问题，拆成两章。

### 4.3 专栏页（查询型）

统一模板：

```text
┌ kicker + h1 + lede ────────────────────────────────────────────────┐
│ [筛选 chips] [搜索框] [打印] [视图切换]                            │
├ 内容区 ─────────────────────────────────────────────────────────────┤
│ 卡片网格 / 决策树 / 流程地图 / 表格                                  │
└────────────────────────────────────────────────────────────────────┘
```

每个专栏有一个隐喻和一种主交互：

| 页面 | 隐喻 | 主交互 | 内容单元 |
| --- | --- | --- | --- |
| 生物绘图专区 | 图鉴 / 画廊 | 按问题选图、图层解剖 | 图表配方卡 |
| 生物信息专区 | 航线图 | 点节点看工具与检查点 | 流程节点 |
| 数据诊所 | 诊室 | 病例筛选、诊断展开 | 病例卡 |
| 统计导航 | 路标 | 决策树问答 | 决策节点 |
| R 代码急救室 | 急救室 | 搜报错、按症状分诊 | 报错卡 |
| 数据集标本馆 | 标本馆 | 按分析类型/章节筛选 | 数据集卡 |
| 课题工作台 | 工作台 | 勾选交付物、看下一步 | 任务与槽位 |

专栏页必须支持：
- 深链接到单个单元（`#case-batch`、`#node-deseq2`）；
- 从章节正文反向链接（「在数据诊所查看完整病例」）；
- 打印/导出当前筛选结果；
- 无结果空状态与建议关键词。

### 4.4 速查表页

- 顶部：搜索、分类 chips、直达按钮、打印。
- 卡片流：每张卡一个主题，支持复制。
- 分类：基础语法 / 数据处理 / 可视化 / 统计建模 / 科研工具 / 生物信息 / 数据库与格式。
- 科研工具卡带 `RESEARCH TOOL` 徽标。
- 每张卡可深链接（`#dplyr-verbs`）。
- 打印：按分类分页，卡片不跨页。

### 4.5 术语表页

- 三个分类：R / 统计 / 生物。
- 每条：中文名、英文名、一句话定义、公式（可选）、对应 R 函数、相关章节。
- 支持搜索与字母/拼音索引。
- 正文中的术语首次出现由 `glossary.js` 包成 tooltip；不重复包裹。

### 4.6 课题工作台

**任务**：把 18 章从「课程」变成「一个课题」。

内容：
- 顶部：研究问题、数据清单、总体进度环。
- 交付物看板：18 个交付物，按阶段分组；每项显示章节、文件、状态、下一步。
- 图表槽位：Figure 1–5、Table 1–2；未完成显示占位与所需章节。
- 方法学清单：研究设计、统计方法、软件版本、数据可得性。
- 可复现清单：项目结构、renv、Quarto、原始数据只读、脚本编号、图由代码生成。
- 「导出研究日志」：打印当前状态为 PDF（只打印工作台，不打印全站）。
- 「下一步」按钮：跳到最靠前的未完成章节。

工作台不要求后端；所有状态来自 localStorage，导出为打印。

### 4.7 可选：R 沙盒

- 只在 Phase 4 评估；独立页面，不进入主线导航。
- 若采用 WebR：本地 vendored WASM，首次加载明确提示体积；只支持 base R + 少量预装包；不承诺 Bioconductor。
- 页面顶部必须写清「沙盒不能替代本地 RStudio；包版本与真实分析不同」。
- 不默认加载；用户点击「启动沙盒」后才初始化。

## 5. 搜索

### 5.1 语料

构建时生成 `assets/js/search-index.js`，包含：

| 类型 | 字段 |
| --- | --- |
| 章节 | id, title, question, keywords, part, summary, headings |
| 速查 | id, title, category, keywords, first 200 chars |
| 专栏单元 | id, page, title, keywords, summary |
| 术语 | term, en, aliases, definition |
| 数据集 | id, title, variables, research_question |

### 5.2 交互

- `Ctrl/Cmd + K` 或点击搜索按钮。
- 输入即时过滤；中文用子串，英文用 token 前缀。
- 分组显示，每组最多 6 条；回车打开第一条。
- 高亮匹配片段（只高亮文本，不插入 HTML）。
- 空状态：建议关键词 + 「浏览全部章节」。

### 5.3 排序

1. 标题精确匹配；
2. 标题前缀；
3. 关键词精确；
4. 正文包含；
5. 同分按「章节 < 速查 < 专栏 < 术语」排序。

不做模糊拼写纠正；不做语义搜索。

## 6. 进度与状态

### 6.1 localStorage 键

| 键 | 内容 | 版本 |
| --- | --- | --- |
| `bior.theme` | `light` / `dark` / `auto` | v1 |
| `bior.fontscale` | 0.8–1.4 | v1 |
| `bior.progress` | `{version:1, chapters:{ch01:{done:true,at:"ISO"}}}` | v1 |
| `bior.mastery` | `{version:1, items:{ch01-o1:"know" / "unsure" / "no"}}` | v1 |
| `bior.last` | 最后访问的章节 id | v1 |
| `bior.deliverables` | `{version:1, items:{ch06:true}}` | v1 |
| `bior.palette` | 搜索历史（最多 8 条） | v1 |

规则：
- 所有读写包在 `try/catch`；损坏数据自动重置。
- 不存任何个人身份信息。
- 不做跨设备同步。
- 提供「重置学习记录」入口（关于页/工作台底部）。

### 6.2 完成逻辑

- 章节「标记完成」只写 `bior.progress`，不要求做完 quiz。
- 交付物勾选独立于章节完成；工作台可分别显示「学过」与「产出」。
- 首页「继续学习」取最后访问且未完成的章节；若都完成，取最后一个访问章节。
- 「今日任务」= 最靠前的未完成章节 + 一句为什么现在学。

### 6.3 掌握度

- 学习目标每条右侧三态按钮：知道 / 不确定 / 不知道。
- 「不知道」的条目汇总到首页「需要回看」面板。
- 不计算分数，不排名，不制造焦虑。

## 7. 页面元数据

每个页面 `<head>` 必须包含：

```html
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>第 6 章 数据整形：把 60 只鼠兔整理成一张表 | bioR</title>
<meta name="description" content="用 dplyr 完成按海拔分组的描述统计，产出 Table 1；含 R console、图形与科研任务。">
```

章节页额外：

```html
<body data-page="chapter" data-chapter="ch06" data-part="II">
```

专栏页：

```html
<body data-page="special" data-special="bioviz">
```

用途：导航高亮、脚本按页初始化、打印页脚、搜索统计。

## 8. 交叉链接规则

- 每章至少链接：1 张相关速查表、1 个相关专栏单元、上一章/下一章。
- 每个专栏单元至少链接：1 个章节、1 张速查表。
- 统计导航的每个结果必须链接到对应章节 + 报告模板。
- 绘图图鉴每张配方卡必须链接到 ch08 或 ch09。
- 生信流程节点必须链接到 ch18 或对应速查表。
- 数据诊所每个病例必须链接到「正确做法」所在章节。
- 急救室每条报错必须链接到最可能出错的章节。
- 数据集卡片必须列出「用于哪些章」。
- 所有内部链接使用相对路径；不使用 `target="_blank"`（站内）。

## 9. 空状态与错误状态

| 场景 | 文案 | 动作 |
| --- | --- | --- |
| 搜索无结果 | 「没有找到『xxx』。试试：t 检验、热图、join、DESeq2」 | 清空搜索 / 浏览章节 |
| 速查筛选无结果 | 「这个分类下还没有卡片。」 | 查看全部分类 |
| 章节未完成 | 工作台显示「需要先完成 ch06 的数据整形」 | 跳到该章 |
| localStorage 损坏 | 静默重置，控制台警告 | 无 UI 打扰 |
| 图缺失 | 显示占位框 + 「图形生成失败，请运行 tools/render-figures.R」 | 不显示破图 |
| 脚本加载失败 | 页面仍可读；交互按钮隐藏 | 控制台错误 |

## 10. 演示与带教模式（可选）

- `?present=1`：隐藏顶栏/右栏/页脚，只保留正文；方向键翻页；`Esc` 退出。
- 带教模式 `?teacher=1` 或 `Ctrl+Alt+T`：显示测验答案与讲解器全部帧；用于课堂。
- 两者都不改变内容，不写进度。
- 打印不受演示模式影响。

## 11. 页面验收清单

- [ ] 首页 30 秒内能回答「从哪开始 / 上次到哪 / 能查什么」。
- [ ] 每章有封面问题、科研情境、任务、交付物、方法学句式、研究日志。
- [ ] 每个专栏单元可深链接，且能从至少一章反向到达。
- [ ] 搜索覆盖章节、速查、专栏、术语、数据集；`Ctrl K` 可用。
- [ ] 进度、掌握度、交付物三种状态独立且可重置。
- [ ] 空状态有建议，不是死胡同。
- [ ] 所有页面在 390 / 768 / 1024 / 1440 宽度无页面级横向滚动。
- [ ] 打印章节得到可读的 A4 讲义。
