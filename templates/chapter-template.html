本章科研问题：把原始表整理成一张可分析的表，需要哪几步？

70 MIN前置 无数据 pika_physiology.csv交付 table1_group.csv

学习目标

  • 说出一章必须包含的 13 个块及其顺序。
  • 为代码卡写 data-example 并与 tools/examples/ 对应。
  • 用统计正确性规则检查自己的草稿。

前置：无；数据：pika_physiology.csv；交付：见封面。

课题第一天，导师把 60 行的测量表交给你：「先告诉我三个海拔点的体重各是多少，别急着做检验。」这一章教你把原始表整理成能回答这句话的汇总表。

1. 一行一个动作：代码卡怎么写

每个代码卡只讲一个动作。代码必须与 tools/examples/ 中的脚本一致，输出由脚本生成。

逐行解释

  • 第 1 行：载入读数据的包。
  • 第 2–3 行：here::here() 从项目根目录出发找文件，避免 setwd()；show_col_types = FALSE 关闭列规格消息，保持输出干净。
  • 第 4 行：tibble 默认只打印前 10 行，并标注每列类型。

base R 对照

pika <- read.csv(here::here("assets/data/pika_physiology.csv"))
head(pika)

常见错误

read.csv() 会把字符串列自动转因子（R < 4.0）或改列名（check.names），与 read_csv() 行为不同；教学代码统一用 readr。

示例 2：按海拔汇总体重（Table 1 的雏形）

dplyr::summarise科研必会
library(dplyr); library(readr)
pika <- read_csv(here::here("assets/data/pika_physiology.csv"),
                 show_col_types = FALSE)
pika |>
  group_by(altitude_group) |>
  summarise(
    n = n(),
    mean_mass = mean(body_mass_g, na.rm = TRUE),
    sd_mass = sd(body_mass_g, na.rm = TRUE)
  )
R console
# A tibble: 3 × 4
  altitude_group     n mean_mass sd_mass
  <chr>          <int>     <dbl>   <dbl>
1 high              20      168.    16.3
2 low               20      180.    15.9
3 mid               20      179.    16.5

逐行解释

  • 第 1 行：载入数据整形与读入的包；两个包同一行载入是为了让脚本自包含。
  • 第 2–3 行：每个示例都可独立运行，因此这里重新读入数据。
  • 第 4 行：把表送入管道。
  • 第 5 行：定义三个组；group_by() 不改变行数。
  • 第 6–10 行：每组返回一行；na.rm = TRUE 让含缺失的列仍能计算。

base R 对照

aggregate(body_mass_g ~ altitude_group, data = pika,
          FUN = function(x) c(mean = mean(x), sd = sd(x)))

常见错误

省略 na.rm = TRUE 时，只要组内有缺失，均值就是 NA；n() 统计的是行数（含缺失），报告 n 时应写清口径。

科研任务：生成 Table 1

把方法用到自己的数据上。完成后你将得到本章交付物。

  1. 定规则：写下缺失与离群值的排除规则，存入 exclusions.csv。
  2. 做汇总：按海拔 × 性别计算 n、均值、SD。
  3. 查结果：确认每组 n 与设计一致（每格 10 只）。

检查点

  • 每组 n 之和 = 清洗后总行数。
  • 均值计算没有混入 NA。
  • 导出的 CSV 列名可读、单位写明。

常见错误

Error in mean(body_mass_g) : object 'body_mass_g' not found

病因：列名不是独立对象；body_mass_g 是 pika 的列。

修复：mean(pika$body_mass_g, na.rm = TRUE)，或在 dplyr 动词内直接引用。

预防：先 glimpse(pika)，用 RStudio 自动补全。

排除规则必须在看到检验结果之前定死；Table 1 要写清 n、均值±SD 还是中位数(IQR)，以及缺失处理方式。

Group means and standard deviations were calculated for each altitude group (n = 20 per group).

中文：按海拔分组计算均值与标准差，每组 n = 20。
